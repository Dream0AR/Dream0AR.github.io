Figure -- The graph $X$ consists of **vertex set**$V(X),$ **edge set**$E(X)$. Each (undirected) edge is an unordered pair $\{x,y\},$ often represented by $xy$. If $xy\in E,$ Then $x, y$ points are said to be **adjacent**, denoted as $x\sim y.$ If there is a bijection $\varphi: V(X)\rightarrow V(Y),$ Let $x\sim y$ in $V(X)$ if and only if $\varphi(x)\sim\varphi(y),$ in $V(Y)$ Then the graph $X$ and $Y$ are said to be **isomorphic**. When drawing representations, numbers are often used to label the vertices. A graph is said to be complete if every pair of its vertices are adjacent. Remember that a complete graph with $n$ vertices is $K_n.$. The graph is said to be **empty**, If the edge set is an empty set and has at least one vertex; the graph is said to be **null**, If the edge set and the point set are both empty sets. These two concepts are proposed for narrative convenience. The previous graphs are all **simple graphs**. Sometimes the edge set $E(X)$ is replaced by the directed edge set $A(X),$ It is called **directed graph**. At this time, the edges are ordered pairs, which are represented by arrows in the diagram and are called **arcs**. An undirected graph is sometimes also considered as a directed graph in which each undirected edge is two directed edges. Generally, simple graphs are considered by default. The vertex set can actually have an infinite number of elements, But this book considers **finite graphs** by default. subplot ---- If the graph $Y$ satisfies $V(X)\subset V(Y),$ $E(X)\subset E(Y),$ Then $Y$ is called the **subgraph** of $X$. If $V(Y)=V(X),$ also satisfies $V(Y)=V(X),$, then $Y$ is called the **generated subgraph** of $X$. If the vertices in a subgraph $Y$ are adjacent if and only if they are adjacent in $X$, then $Y$ is said to be an induced subgraph of $X$. It can be seen that the generated subgraph is obtained by deleting edges, while the induced subgraph is obtained by deleting points and their adjacent edges. There are several important concepts related to subgraphs: If a subgraph is a complete graph, it is called a clique. If the induced subgraph of a vertex set is empty, it is called an independent set. The size of the largest clique in graph $X$ is denoted as $\omega(X), and the size of the largest independent set is denoted as $\alpha(X).$ These are two very important properties of graphs. The **road** with length $r$ from vertex $x$ to $y$ on the graph, Refers to a sequence composed of $r+1$ different vertices, with $x$ as the head and $y$ as the tail. And adjacent vertices in the sequence are also adjacent in the graph. If any two points on the graph have roads starting and ending with them, Then the graph is said to be **connected**, otherwise it is said to be disconnected. The graph is disconnected, which is equivalent to that we can divide the graph $X$ vertex set into two sets $R, S, $ So that the vertices in $R$ and the vertices in $S$ are not adjacent. At this time we can say that the graph $X$ is the intersection-free union of the vertex sets $R$ and $S$ induced subgraphs. A maximum connected induced subgraph, It is called the **connected branch** of the graph $X$, abbreviated as **branch**. A cycle refers to a connected graph, where each vertex has exactly two neighbors; A ring in a graph refers to a ring that is a subgraph. It is easy to prove that if every point in the graph has at least two neighboring points, Then the graph must contain a cycle. A connected acyclic graph is called a **tree**, The acyclic graph can be split into the non-intersecting union of several maximal connected acyclic graphs, so it is called **forest**. If a spanning subgraph is a tree, it is called a spanning tree. It is easy to see that a graph has a spanning tree if and only if it is connected. A maximal spanning forest refers to a spanning subgraph composed of spanning trees for each branch. automorphism ------ The isomorphism of graph $X$ to itself is an automorphism. It is easy to prove that all automorphisms form a group, Denoted as $\operatorname{Aut}(X).$ Obviously $\operatorname{Aut}(X)\subset \operatorname{Sym}(V(X)).$ The latter refers to the symmetry group, that is, all permutations of the set $V(X)$. A basic example is $\operatorname{Aut}(K_n)\cong \operatorname{Sym}(V(K_n))=S_n.$ Generally speaking, it is not easy to determine whether two graphs are isomorphic, and whether a graph has non-trivial automorphism. The image of $v$ under the substitution of $g$ is denoted as $v^g.$ When $g\in \operatorname{Aut}(X)$, For the subgraph $Y\subset X,$, the subgraph $Y^g\subset X.$ can be defined edge-preservingly. $Y$ and $Y^g$ are naturally isomorphic. The **degree/valency** of vertex $x$ refers to the number of neighbors of $x$. The maximum (minimum) degree of graph $X$, That is, it refers to the maximum (minimum) value of all vertex degrees. If the degree of each vertex of the graph is $k,$ It is called **$k-$regular graph**. **Lemma 1.1**. *If $x\in X,$ $g\in \operatorname{Aut}(X),$ then $x$ has the same degree as $x^g$.* **Certificate:** Just use the induced subgraph $N(x)$ of $x$ and all its neighbors to satisfy $N(x)\cong N(x)^g=N(x^g)$. The **distance**$d_X(x,y),$ between two vertices $x,y$ in the graph $X$ refers to the length of the shortest path connecting $x,y$. If $X$ is clear, the distance can be abbreviated as $d(x,y).$ A simple lemma is as follows: **Lemma 1.2**. *$\,\forall\,x,y\in X,$ $g\in \operatorname{Aut}(X),$ $d(x,y)=d(x^g,y^g).$* The **complementary graph**$\overline X$ of the graph $X$ is such a graph: It satisfies $V(X)=V(\overline X),$ But two vertices are adjacent in $\overline X$ if and only if they are not adjacent in $X$. It is easy to prove the following lemma: **Lemma 1.3**. *$\operatorname{Aut}(X)\cong \operatorname{Aut}(\overline X).$* If $X$ is a directed graph, then for isomorphism, we require it to be direction-preserving. homomorphism ---- Mapping $f:V(X)\rightarrow V(Y)$ to two graphs $X,Y,$ is called **homomorphism,** If $x\sim y\in X\Rightarrow f(x)\sim f(y)\in Y.$, the previous isomorphism is of course also a isomorphism. The graph $X$ is a **bipartite graph**, if $V(X)$ can be divided into $V_1, V_2,$ Such that the endpoints of each edge are in these two sets respectively. An example of a homomorphism is $V(X)\rightarrow V(K_2),$ mapping $V_i$ to vertex $i$. This example raises the issue of graph coloring. The **normal coloring (proper coloring)** of a graph, It refers to the mapping from $V(X)$ to a certain finite (color) set, so that adjacent points are mapped to different colors. If $X$ can be dyed normally by $k$ colors, it is said to be dyeable by $k-$**. The smallest $k$ is called the **chromatic number** of the graph $X$, recorded as $\chi(X).$ All points dyed with a certain color form an independent set, called a color class. For a bipartite graph with at least one edge, its coloring number is $2.$ **Lemma 1.4**. *The coloring number of $X$ is the smallest $r,$ such that there is a homomorphism of $X\rightarrow K_r$.* **Proof:** For homomorphism $f:X\rightarrow Y,$ it is easy to see for $y\in Y,$ $f^{-1}(y):=\{x\in V(X): f(x)=y\}$ is an independent set. Therefore, if there is a homomorphism from $X$ to $K_r$, Taking $K_r$ vertices as $r$ different colors, just color the vertices in $X$ according to their images, Thus $\chi(X)\le r.$ If $\chi(X)$ can be dyed by $r-$, let the color set be $\{1,\cdots,r\},$ Just map each color class to the corresponding vertex in $K_r$. Because the adjacent points in $X$ have different colors, And different colors are adjacent to each other in $K_r$. The homomorphism $f$ of graph $X$ to its subgraph $Y$ is called contraction, if $f|_Y$ is an identity mapping. At this time, $Y$ is called the contraction kernel of $X$. For example, in the following figure, construct a homomorphism as shown by the red arrow, Then the five inner sides form the contraction core of the original image. For the homomorphism of directed graphs, just change the preservation of adjacency to the preservation of ordered pairs. It should be noted that, The above discussion assumes that there is no loop in the graph. An edge is called a loop if its two endpoints are the same point. The properties of homomorphisms of graphs that allow cycles will be quite different. An example is that any mapping from a set of vertices to a point with a cycle is homomorphic. The homomorphism of graph $X$ to itself is called an automorphism, and all automorphisms constitute a monoid group. The automorphism group is included in it. cycle diagram ------ Next, we introduce a very important type of graph, called circulant graph: It is a directed graph $X=X(\mathbb{Z}_n,C),$ The vertex of the set $C\subset \mathbb{Z}_n\setminus\{0\}.$ is the element in $\mathbb{Z}_n$, $(i,j)$ is an arc in $X$ if and only if $j-i\in C.$ $X(\mathbb{Z}_n,C)$ is called a cyclic graph of order $n$, with $C$ as a connected set. If $\,\forall\,c\in C,$ $-c\in C,$ then $(i,j)$ is an arc if and only if $(j,i)$ is an arc, Therefore $X$ can be regarded as an undirected graph. It is easy to see that the ring mentioned above is $X(\mathbb{Z}_n,\{\pm 1\}),$ It is a type of cyclic graph, denoted as $C_n$. Johnson diagram ---------- For positive integers $v\ge k\ge i,$ the graph $J(v,k,i)$ is such an undirected graph: Let there be a set $\Omega,$ with $v$ elements The graph takes all subsets containing $k$ elements in $\Omega$ as vertices, An edge is connected between two points if and only if the intersection of its corresponding subsets contains $i$ elements. Therefore, it contains $\binom{v}{k}$ vertices, It is a regular graph, and each point has $\binom{k}{i}\binom{v-k}{k-i}$ as its degree. **Lemma 1.5**. *$J(v,k,i)\cong J(v,v-k,v-2k+i).$* **Proof:** Just map each subset containing $k$ elements to its complement in $\Omega$. It is easy to see that the intersection of two complementary sets contains $v-2k+i$ elements if and only if the original two sets contain $i$ elements. Therefore such mappings are isomorphic. According to this lemma, we can always default to $v\ge 2k.$. At this time, $J(v,k,k-1)$ is called **Johnson graph**, $J(v,k,0)$ is the **Kneser graph**. Since the replacement of elements in $\Omega$ induces the replacement between subsets, We have the following lemma: **Lemma 1.6**. *$S_v\subset \operatorname{Aut}(J(v,k,i)).$* side picture ---- The **edge graph (line graph)**$L(X)$ of the graph $X$ is such a graph: it has the edges of $X$ as vertices, Two vertices are connected by an edge if and only if their corresponding edges in $X$ have common vertices. **Star graph**$K_{1,n}$ is a graph composed of $1$ vertices and their $n$ neighbors. Its edge graph is the complete graph $K_n.$ For the ring $C_n,$ it is isomorphic to its edge graph. Considering its two vertices for each edge, we have the following lemma: **Lemma 1.7**. *If $X$ is a $k-$regular graph, then $L(X)$ is $2k-2$regular.* Each vertex of degree $k$ in $X$ determines a clique of size $k$ in $L(X)$. If $X$ contains $n$ vertices, Then there are corresponding $n$ clusters in $L(X)$, so that each vertex of $L(X)$ is in at most two of the clusters, Each edge is in exactly one of the groups. In fact, through the construction method, there is the following inverse proposition: **Theorem 1.8** (Krausz). *A non-empty graph is an edge graph of a graph if and only if its edge set can be divided into several cliques, such that each vertex is in at most two of the cliques.* If $X$ does not contain **triangle** (a group with size $3$), then when a point in $L(X)$ has two neighboring points, When two neighboring points are in a certain group as mentioned above, this point is also in that group. Otherwise, their corresponding sides form a triangle at $X$. Therefore, the cliques in $L(X)$ determined by the vertices of $X$ are all maximal. Obviously $X\cong Y\Rightarrow L(X)\cong L(Y),$ but the reverse is not necessarily true, For example $L(K_{1,3})\cong L(K_3).$ However, Whitney proved that this is in fact the only counterexample in the connected case. Let us prove the weaker proposition below. **Lemma 1.9**. *If the minimum degree of $X,Y$ is greater than $3,$ then $X\cong Y\Leftrightarrow L(X)\cong L(Y).$* **Proof:** Just note that in the side plot, A cluster containing less than three points may not necessarily be reduced to a star graph starting from a certain vertex. However, when a group with more than three points is restored, it must be restored to a star graph. It only needs to be explained that when four sides have common vertices in pairs, It must be in the shape of $K_{1,4}$. Otherwise, three of the sides must be restored to a triangle when restored. At this time, it is impossible to add a fourth edge so that both sides have common vertices. Therefore, when the degree of each vertex is greater than $3$, The size of $n$ maximal cliques corresponding to $n$ vertices is greater than $3,$ And conversely, each maximal clique with a size greater than $3$ corresponds to a vertex. Therefore, there is a bijection between the vertex set and the maximum group with size greater than $3$, And the vertices are adjacent if and only if the corresponding maximal cliques have common points. Therefore, the properties of the graph and its edge graph properties determine each other, Therefore $X\cong Y\Leftrightarrow L(X)\cong L(Y).$ Another interesting description of edge graphs is: **Theorem 1.10** (Beineke). *A graph is an edge graph if and only if its induced subgraphs each containing at most six points are edge graphs.* We call a bipartite graph **semi-regular** if it has 2$-coloring such that points with the same color have the same degree. The simplest example is **complete bipartite graph**$K_{m,n},$ It consists of two independent sets containing $m$ points and $n$ points, connected in pairs. **Lemma 1.11**. *If the edge graph $L(X)$ of the connected graph $X$ is a regular graph, then $X$ is a regular or semi-regular bipartite graph.* **Proof:** Suppose $L(X)$ is $k-$ regular, then the sum of the degrees of each pair of neighboring points in $X$ is always $k+2.$ Therefore, the degree of all points in connected $X$ can only take on at most two values. If there is only one value, Then it is a regular graph; if there are two different values, then just color it according to these two values. In this way, only the sum of point degrees of different colors meets the requirements, so points of the same color must not be adjacent. And after dyeing in this way, points with the same color have the same degree, which is semi-regular. Available floor plan -------- We have seen that it is convenient to represent graphs graphically. If the graph can be drawn without intersecting lines, It is called a planar graph. More precisely, we consider mapping the graph onto a plane. Map vertices to points and edges to continuous curves connecting two points without self-intersection, Such a mapping is called **Plane Embedding**. If the corresponding curves of the edges without common points do not intersect, Curves corresponding to edges with common vertices only intersect at corresponding points on the plane. A graph is called planar if and only if there exists such a planar embedding. **Plane graph** is a planar graph with good plane embedding. The edges of a plan view divide the plane into several areas, which are called the **faces** of the plan view. Except for one area, All other areas are bounded. This unbounded area is called the **infinity surface** or **external (external). face)**. The length of a face refers to the number of sides that frame it. The famous Euler's formula gives the relationship between points, lines and surfaces in a plane diagram: **Theorem 1.12** (Euler). *If a connected plane graph has $n$ vertices, $e$ edges and $f$ faces, then $n-e+f=2.$* A planar graph is called a maximally planar graph. If one more edge is added, it is no longer planar. If the plane of a planar graph is embedded with a face whose length is greater than $3$, then it is possible to add another edge. Therefore, the plane embedding of a maximally planar graph has the length of all faces $3$. If the degree of each point is at least $2$, Then each edge lies in exactly two faces, and we have $2e=3f,$ so $e=3n-6.$ In fact, if a planar graph containing $n$ points has $3n-6$ edges, it must be maximal. Such a graph is called a plane triangulation. There are many kinds of planar embeddings for a graph, which will cause the faces of the planar graph to be different, as shown in the figure below. A very important topological conclusion is that $3-$ connected graphs essentially have only one embedding method. Given a planar graph $X,$ we can generate **dual graph**$X^\ast,$ Taking the face of $X$ as the vertex of $X^\ast$, for each common edge between two faces in $X$, Draw an edge in $X^\ast$ (across a common edge) connecting the corresponding vertices on both sides. Note that there may be multiple edges in $X^\ast$, that is, there are multiple edges connecting two points. Unless otherwise specified, we do not consider duplicate edges in the graph by default. If a graph is isomorphic to its dual graph, it is called **self-dual**, such as the complete graph $K_4.$ For a connected graph $X,$ we can explain $X\cong (X^\ast)^\ast.$ The concept of embedding can be generalized from the plane to any surface, and the duality is similar. An example is that the complete graph $K_6$ of a non-planar graph can be embedded on the projective plane, is a triangulation of the projective plane. Another example is that the complete graph $K_7$ is not a planar graph and cannot be embedded on the projective plane, But it can be embedded on the torus.
