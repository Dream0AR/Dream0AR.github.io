de Rham Cohomology is the most important diffeomorphic invariant of manifolds, and invariants are something we are looking forward to. Invariants can be used to quickly distinguish/classify manifolds. $\mathbb{R}^n$ de Rham cohomology -------------------------- ### Differential form The coordinates in $\mathbb{R}^n$ are $(x_1,...,x_n)$, record the independent variable differential $dx_1,...,dx_n$, Introduce the notation $\wedge$(wedge) to satisfy $dx_i\wedge dx_i=0$, $dx_i\wedge dx_j=-dx_j\wedge dx_i$, $i\neq j$. Remember $\Omega^q=\operatorname{span}_R\{dx_{i_1}\wedge\cdots\wedge dx_{i_q}|{}i_{1}<...<{}i_{ {}q}\},$ $\Omega^\ast=\oplus_{q=0}^n \Omega^q$, it is easy to see that its dimension is $2^n$. Remember the smooth $q-$ form as $\Omega^q(\mathbb{R}^n)=C^\infty(\mathbb{R}^n)\otimes_\mathbb{R}\Omega^q$, The overall smooth form is $\Omega^\ast(\mathbb{R}^n)=\oplus_{q=0}^n \Omega^q(\mathbb{R}^n)$. Therefore, any smooth form $\omega\in \Omega^\ast(\mathbb{R}^n)$ can be **decomposed** by type as $\omega=\sum_{q=0}^{n} \omega_q$, $\omega_q\in \Omega^q(\mathbb{R}^n)$. $\omega_q=\sum_{I:{}i_{1}<...<{}i_{ {}q} }f_Idx_I$, $I$ is called **multiple indicators**. ### Operator External product operator $\wedge$: (can be seen as an expanded definition of the original symbol) $\tau=\sum_{I:{}i_{1}<...<{}i_{ {}p} }f_Idx_I\in \Omega^p(\mathbb{R}^n)$, $\omega=\sum_{J:{}j_{1}<...<{}j_{ {}q} }g_Jdx_J\in \Omega^q(\mathbb{R}^n)$, rule $\tau\wedge\omega=\sum_{I,J}f_Ig_Jdx_I\wedge dx_J=\sum_{K:{}k_{1}<...<{}k_{ {}p+q} }h_Kdx_K$. Among them, $h_K$ can be expressed by $f_I, g_J$. **Proposition 1.1**. *$\tau\wedge \omega = (-1)^{pq}\omega \wedge \tau$* External differential operator $d:\Omega^q(\mathbb{R}^n)\rightarrow \Omega^{q+1}(\mathbb{R}^n)$, $\omega=\sum_I f_I dx_I$, $d\omega=\sum_I df_I\wedge dx_I=\sum_{i,I} \frac{\partial {}f_I}{\partial {}x_i}dx_i\wedge dx_I$, It is the natural continuation of the differential operator on $C^\infty$. **Proposition 1.2**. *$\tau\in \Omega^p(\mathbb{R}^n)$, then $d(\tau\wedge \omega)=d\tau \wedge \omega + (-1)^p \tau\wedge d\omega,$ $d^2=0$.* ### de Rham complex Since $d^2=0$, $\{\Omega^\ast(\mathbb{R}^n),d\}$ forms the **de of $\mathbb{R}^n$ Rham complex**: $$\Omega^0(\mathbb{R}^n)\xrightarrow{d}\cdots\xrightarrow{d}\Omega^n(\mathbb{R}^n).$$ You can add $\Omega^q(\mathbb{R}^n)=0$ to $q<0$ and $q>n$. Definition$Z^q(\mathbb{R}^n)=\{\omega\in\Omega^q(\mathbb{R}^n)|d\omega=0\},$ where the elements are called **closed**$q$-forms. Definition $B^q(\mathbb{R}^n)=\{d\tau | \tau\in\Omega^{q-1}(\mathbb{R}^n)\},$ where the elements are called **proper**$q$-forms. In particular, It is stipulated that $Z^n(\mathbb{R}^n)=\Omega^n(\mathbb{R}^n),$ $B^0(\mathbb{R}^n)=0.$ Since $d^2=0$, $B^q(\mathbb{R}^n)\subset Z^q(\mathbb{R}^n).$ Define the $q$th de of $\mathbb{R}^n$ Rham cohomology is $H^q_{dR}(\mathbb{R}^n)=Z^q(\mathbb{R}^n)/B^q(\mathbb{R}^n).$ When no ambiguity is caused, subscripts are usually omitted. The cohomology class of the closed $q$-form $\omega$ is denoted as $[\omega].$ Similarly, for the de Rham complex on $\mathbb{R}^n$ open set $U$, Just set the domain of the smooth function to $U$ at the beginning. We have **Cohomological Poincaré's Lemma**: $H^q(\mathbb{R}^n)=\begin{cases} \mathbb{R}\quad&q=0\\ 0&q\neq 0 \end{cases}.$ cohomology -------- Remember $\Omega^\ast_c(\mathbb{R}^n)=C^\infty_c(\mathbb{R}^n)\otimes_\mathbb{R}\Omega^\ast,$ That is to say, the smooth function is changed into a smooth function with compact support set. Similarly, it can be decomposed according to the shape. Since the set of partial derivative supports of smooth functions is contained in the original compact support set, it also has compact support, Therefore $\{\Omega^\ast_c(\mathbb{R}^n),d\}$ is a complex shape, which is called de with compact support Rham complex**. Similarly, Definition$Z^q_c(\mathbb{R}^n)=\{\omega\in\Omega_c^q(\mathbb{R}^n)|d\omega=0\},$ $B^q_c(\mathbb{R}^n)=\{d\tau | \tau\in\Omega_c^{q-1}(\mathbb{R}^n)\},$ $H^q_{c}(\mathbb{R}^n)=Z^q_c(\mathbb{R}^n)/B^q_c(\mathbb{R}^n).$ Note that $Z_c^q(\mathbb{R}^n)=\Omega^q_c(\mathbb{R}^n)\cap Z^q(\mathbb{R}^n),$ But generally $B^q_c(\mathbb{R}^n)\neq B^q(\mathbb{R}^n)\cap \Omega_c^q(\mathbb{R}^n).$ That is, it is not that $d\tau$ has a compact support set but $\tau$ in $d\tau$ has a compact support set. We have **Compactly cohomological Poincaré's Lemma**: $H^q_c(\mathbb{R}^n)=\begin{cases} \mathbb{R}\quad&q=n\\ 0&q\neq n \end{cases}.$ Note that this illustrates that compact cohomology is not homotopy invariant. Similarly, We can define $H_c^\ast(U)$ for general $U\subset \mathbb{R}^n$. differential complex -------- The vector space direct sum $C=\oplus_{q\in\mathbb{Z}} C^q$ is called **differential complex**, If there is a homomorphism $d:C\rightarrow C,$ satisfies $d:C^q\rightarrow C^{q+1},$ $d^2=0.$ Cohomology can be defined for a complex by $d$. The de Rham complex is a differential complex. As in algebraic topology, we can define chain mappings between complexes and their induced homomorphisms, short exact sequences of complexes, And the crucial zig-zag lemma (graph tracing defines homologous long exact sequences).
