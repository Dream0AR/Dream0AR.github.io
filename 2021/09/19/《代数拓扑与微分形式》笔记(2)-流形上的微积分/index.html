Reference book: Warner "Basics of Differential Manifolds and Lie Groups" Differential forms on manifolds ---------------- ### Pull back mapping The smooth function $f:\mathbb{R}^n\rightarrow \mathbb{R}^m$ can induce the pullback mapping $f^\ast :\Omega^0(\mathbb{R}^m)\rightarrow\Omega^0(\mathbb{R}^n)$, $f^\ast (g)=g\circ f$; At the same time, it can also induce $f^\ast :\Omega^1(\mathbb{R}^m)\rightarrow \Omega^1(\mathbb{R}^n)$, $f^\ast (dy_i)=df_i=d(y_i\circ f)$. It is easy to extend this definition to get $f^\ast :\Omega^\ast (\mathbb{R}^m)\rightarrow\Omega^\ast (\mathbb{R}^n)$, $f^\ast (g_Idy_{i_1}\wedge ...\wedge dy_{i_q})$ = $f^\ast (g_I)f^\ast (dy_{i_1}\wedge ...\wedge dy_{i_q})=(g_I\circ f)df_{i_1}\wedge ... \wedge df_{i_q}$. The definition on the $0$ dimension is more natural. Why does the $1$ dimension need to define the basis $dy_i$ in this way? You need to think about it. We know $d:\Omega^0\rightarrow \Omega^1$, Found $df^\ast (g)=d(g\circ f)=\sum_i\frac{\partial {}g\circ f}{\partial {}f_i}df_i$, $dg=\sum_i\frac{\partial {}g}{\partial {}y_i}dy_i$. Note that $f^\ast (\frac{\partial {}g}{\partial {}y_i})=\frac{\partial {}g\circ f}{\partial {}f_i}$, So it is quite natural for us to define $f^\ast (dy_i)=df_i$. At the same time, from the above analysis we get the following proposition: **Proposition 1.1** (Commutatability). *$df^\ast =f^\ast d$.* It can also be said that our definition is based on the hope of satisfying exchangeability. ### First-order differential invariance Let $f:\mathbb{R}^n\rightarrow\mathbb{R}^n$ be a diffeomorphism, $f_i=x_i\circ f$ is the new coordinate, which is called the coordinate defined by diffeomorphism $f$. According to the chain rule, $dg=\sum_{i=1}^{n}\frac{\partial {}g}{\partial {}f_i} df_i=\sum_{i, j=1}^{n}\frac{\partial {}g}{\partial {}f_i}\frac{\partial {}f_i}{\partial {}x_j} dx_j=\sum_{j=1}^n \frac{\partial {}g}{\partial {}x_j}dx_j,$ So $dg$ has nothing to do with the coordinate system, which is to say **first-order differential invariance**. **Pullback mapping and first-order differential invariance are the basis for defining differential forms and differential operators $d$ on manifolds.** ### Differential form on manifold Let $M$ be a smooth $n$-dimensional manifold, $\{(U_\alpha, \phi_\alpha)\}_{\alpha\in\Lambda}$ is the coordinate atlas. The differential form $\omega$ on $M$ is a set class $\{\omega_\alpha\in \Omega^\ast (U_\alpha)\}$, This set class needs to satisfy the compatibility conditions: $\,\forall\,U_\alpha\cap U_\beta\neq \varnothing$, Remember $U_\alpha\cap U_\beta=U_{\alpha\beta}$, $\omega_\alpha|_{U_{\alpha\beta} }=\omega_\beta|_{U_{\alpha\beta} }$, In this way, the differential forms given locally can be assembled into a whole, That is, the set class $\{\omega_\alpha\in \Omega^\ast (U_\alpha)\}$ is spelled into $\omega$. Here $\omega_\alpha=\sum_I {f_\alpha}_I d{\phi_\alpha}_I$, $\phi_\alpha:U_\alpha\approx \mathbb{R}^n$, That is, the differential form on the surface patch is pulled into $\mathbb{R}^n$ for consideration. The definition of $\omega_\alpha|_{U_{\alpha\beta} }$ is by embedding $i:U_{\alpha\beta}\rightarrow U_\alpha$, Pulled from $\Omega^\ast (U_\alpha)$ back to $\Omega^\ast (U_{\alpha\beta})$, That is, it is defined as $i^\ast \omega_\alpha$. Let the differential form on $M$ be $\Omega^\ast (M)$. Similarly, the differential operator $d$ and the outer product $\wedge$ can be defined. It should be noted here that due to the requirements for the differential form on the manifold, the compatibility conditions need to be verified. Due to the commutability of $d$ and $i^\ast$, $\{d\omega_\alpha\}$ does satisfy the compatibility condition, It can be spelled as $d\omega$, so it is well defined. The same goes for $\wedge$. Similarly, there is $\Omega^q(M)$ on the manifold, which can be decomposed according to the shape. $\{\Omega^\ast (M),d\}$ is called the de Rham complex of the manifold $M$. Further, $Z^q(M), B^q(M), H^q(M)$ can be defined. Now consider the smooth mapping between manifolds $f:M\rightarrow N$, This induces $f^\ast :\Omega^\ast (N)\rightarrow\Omega^\ast (M)$. Since $d,f^\ast$ is commutative, this induces $f^\ast : H^\ast (N)\rightarrow H^\ast (M)$, $f^\ast [\omega]=[f^\ast \omega]$. In particular, Consider $i:U\rightarrow M$ to be the inclusion map of the open subset, Then there is $i^\ast : H^\ast (M)\rightarrow H^\ast (U)$, $i^\ast [\omega]=[i^\ast \omega]=[\omega|_U]$. Also write $i^\ast [\omega]$ as $[\omega]|_U$, so we have $[\omega]|_U=[\omega|_U]$. unit decomposition -------- **The existence of unit decomposition is the most basic tool for differential manifolds.** We recall that the manifold satisfies the $T_2$ separability axiom and is pseudocompact. $M$上的单位分解是非负光滑函数集族$\{\rho_\alpha\}_{\alpha\in\Lambda}$, It satisfies that every point on $M$ has a neighborhood, and there are only a finite number of $\rho_\alpha$ on which are not zero. In this way $\sum\rho_\alpha$ is meaningful, and further requires that the sum is $1$ everywhere. Since the manifold is quasi-compact, there is always unit decomposition on it. For a given open coverage $\{U_\alpha\}$ (often the open coverage in the coordinate atlas is taken), Being is subject to the decomposition of its units, That is $\operatorname{supp} \rho_\alpha\subset U_\alpha$. Orientation of the manifold ---------- Remember diffeomorphism$T:\mathbb{R}^n\rightarrow \mathbb{R}^n$, $T(y)=x$, denote $T_i=x_i\circ T$, $J(T)=\det (\frac{\partial {}T_i}{\partial {}y_j})$. Since $T$ is a diffeomorphism, $J(T)$ is not zero, so it is either always positive or always negative. When $J(T)>0$, it is said that $T$ is oriented, The opposite is called reverse orientation. Generally, if it is a diffeomorphism between open sets, it is required to be constant positive on all connected branches. This is called Bao Zhi. Suppose $M$ is a smooth manifold, $\{(U_\alpha, \phi_\alpha)\}$ is a coordinate atlas, If $\,\forall\,U_{\alpha\beta}$ is not empty, Diffeomorphism$\phi_\beta\circ \phi_\alpha^{-1}: \phi_\alpha(U_{\alpha\beta})\rightarrow\phi_\beta(U_{\alpha\beta})$ maintains the orientation, Then the coordinate atlas is called an oriented coordinate atlas. If $M$ has an oriented coordinate atlas, it is said that $M$ can be oriented. **Proposition 1.2**. *A $n$-dimensional manifold $M$ is orientable if and only if it has a globally defined smooth $n$ form that is non-zero everywhere.* Note that any two everywhere non-zero $n$-forms $\eta,\eta'$, The only difference between them is a non-zero function $f$: $\eta=f\eta'$. If $M$ is connected, Then $f$ is always positive or always negative. When $f$ is positive, it is said that $\eta and \eta'$ are equivalent. So every everywhere non-zero smooth $n$-form on $M$ falls into two equivalence classes, Each equivalence class is called an orientation of $M$, denoted $[M]$. integrals on manifolds ---------- Let $\omega$ be a smooth $n$-form with compact support in $\mathbb{R}^n$: $\omega=f(x)dx_1\wedge \cdots\wedge dx_n$, Define integral $\int_{\mathbb{R}^n}\omega=\int_{\mathbb{R}^n}fdx_1\cdots dx_n$. Let $T:\mathbb{R}^n\rightarrow\mathbb{R}^n$, $T(y)=x$ be a diffeomorphism, Then we can prove the variable substitution formula: **Proposition 1.3** (Variable substitution). *$dT_1\wedge ...\wedge dT_n=J(T)dy_1\wedge ...\wedge dy_n$.* Thus $T^\ast \omega=T^\ast fdT_1\wedge ... \wedge dT_n=(f\circ T)J(T)dy_1\wedge ...\wedge dy_n,$ Integrate the above equation to get $$\int_{\mathbb{R}^n}T^\ast \omega=\int_{\mathbb{R}^n}(f\circ T)J(T)dy_1\wedge ...\wedge dy_n,$$ And by the integral transformation formula $$\int_{\mathbb{R}^n} \omega=\int_{\mathbb{R}^n}(f\circ T)|J(T)|dy_1\wedge ...\wedge dy_n,$$ Therefore $\int_{\mathbb{R}^n}T^\ast \omega=\pm \int_{\mathbb{R}^n}\omega$, The sign is determined by the sign of $J(T)$. Now give the integral on $M$. Selected orientation $[M]$ and corresponding orientation coordinate atlas $\{(U_\alpha,\phi_\alpha)\}$. Let $\{\rho_\alpha\}$ be the unit decomposition subordinate to $\{U_\alpha\}$, There is a decomposition of $\tau\in H^n_{c}(M)$$\tau=\sum_\alpha \rho_\alpha \tau$. We would like to have $$\int_{[M]}\tau=\sum_\alpha \int_{[M]}\rho_\alpha\tau,$$ Then study the right formula and hope that $$\int_{[M]}\rho_\alpha\tau=\int_{U_\alpha} (\rho_\alpha\tau)|_{U_\alpha},$$ Use variable substitution to pull the integral back to $\mathbb{R}^n$. $$\int_{U_\alpha} (\rho_\alpha\tau)|_{U_\alpha}=\int_{\mathbb{R}^n}(\phi_\alpha^{-1})^\ast (\rho_\alpha\tau)|_{U_\alpha},$$ Note that the integrand form zero is extended outside $\phi(U_\alpha)$. So we will $\int_{[M]}\tau:=\sum_\alpha \int_{\mathbb{R}^n}(\phi_\alpha^{-1})^\ast (\rho_\alpha\tau)|_{U_\alpha}$, If the direction is clear, $\int_{[M]}$ can be rewritten as $\int_{M}$. What needs to be verified is that this definition has nothing to do with the directional coordinate atlas and unit decomposition.
