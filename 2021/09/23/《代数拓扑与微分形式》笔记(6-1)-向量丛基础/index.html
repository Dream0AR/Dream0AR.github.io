Local trivialization of vector bundles ------------------ Continuation of the previous section’s mark. $E_x=\pi^{-1}(x)$ is a vector space. If $\,\exists\,\{U_\alpha\}$ is the open cover of $M$, There is a diffeomorphism $\phi_\alpha:E_{U_\alpha}=\pi^{-1}(U_\alpha)\rightarrow U_\alpha\times \mathbb{R}^n$, Let $E_x\mapsto \{x\}\times \mathbb{R}^n$, and the map be the isomorphism of the vector space, Then $\pi$ is called a smooth (real) **vector bundle** of rank $n$, $\{(U_\alpha,\phi_\alpha)\}$ is **local trivialization**, $E$ and $M$ are called **full space** and **base manifold**. The vector bundle is the fiber $\mathbb{R}^n$, The structure group is the **fiber bundle** of $\operatorname{GL}(n,\mathbb{R})$. If $\mathbb{R}$ is replaced by $\mathbb{C}$, it is a complex vector bundle. By default we discuss smooth real vector bundles. Smooth mapping $s:U\rightarrow E$ is called **section**, if $\pi\circ s=id$, That is, it is required that $s(x)\in E_x$. All sections of $E$ on $U$ are recorded as $\Gamma(U,E)$. **Zero cross-section** refers to $s: M\rightarrow E$, $s(x)=0_x\in E_x$. The $n$ sections $s_1,...,s_n$ on $U$ are called **frame**, if for each point $x\in U$, $s_1(x),...,s_n(x)$ is a set of basis of $E_x$. The natural frame on local trivialization is $\varepsilon_1^\alpha, ...,\varepsilon_n^\alpha$, Defined by $\varepsilon_i^\alpha(x)=\phi_\alpha^{-1}(x,e_i)$. Among them, $e_1,...,e_n$ is the standard unit base. In turn, The frame $s_1,...,s_n$ also gives the trivialization of $E|_U$: $\phi(\sum v_is_i(x))=(x,(v_1,...,v_n))$, That is, the coordinates on $E|_x$ are directly mapped to the coordinates on $\mathbb{R}^n$. **The mutual transformation between the frame and local trivialization is the basic method for studying vector bundles.** **Essence of vector bundle: transfer function.** $\,\forall\,x\in U_{\alpha\beta}$, $\phi_{\alpha}\circ(\phi_\beta)^{-1}:\{x\}\times \mathbb{R}^n\rightarrow \{x\}\times \mathbb{R}^n$ is an automorphism. There exists $g_{\alpha\beta}(x)\in \operatorname{GL}(n,\mathbb{R})$ such that, $\,\forall\,v\in \mathbb{R}^n$, $\phi_\alpha\phi_\beta^{-1}(x,v)=(x,g_{\alpha\beta}(x)v)$. It satisfies **cocycle conditions**: $g_{\alpha\beta}=g_{\beta\alpha}^{-1}\:\:\text{on}\:\:U_{\alpha\beta};$ $g_{\alpha\beta}g_{\beta\gamma}=g_{\alpha\gamma} \:\:\text{on}\:\:U_{\alpha\beta\gamma}.$ **Lemma 1.1**. *If there is another trivialization $\{(U_\alpha,\phi_\alpha')\}$ inducing the transfer function $g_{\alpha\beta}'$, then there is a smooth matrix mapping $\lambda_\alpha,\lambda_\beta$, Such that $g_{\alpha\beta}(x)=\lambda_\alpha(x)g'_{\alpha\beta}(x)\lambda^{-1}_\beta(x)$.* **Proof:** Note that $\phi_\alpha\circ{\phi'_\alpha}^{-1}$ is an automorphism, Can define $\lambda_\alpha$, Such that $\phi_\alpha{\phi'_\alpha}^{-1}(x,v)=(x,\lambda_\alpha(x)v).$ Similarly, define $\lambda_\beta.$ Next, Insert $\phi_\alpha',\phi_\beta'$ appropriately into $\phi_\alpha\phi_\beta^{-1}$ That’s it. Defining the equivalence of two transfer functions means that there is such a smooth matrix mapping that makes them cancel out, Note that the transfer function here is allowed to originate from two different vector bundles. So two different trivializations of the same vector bundle, The corresponding transfer functions are equivalent. The smooth map $f:E\rightarrow E'$ is called a bundle map, H if it maps each fiber to fiber, And it is linear. It also becomes a homomorphism, and its totality is $\operatorname{Hom}(E,E').$ When the restriction is isomorphism on the fiber, $f$ is also called isomorphism, and $E$ and $E'$ are isomorphisms. Reduction of structural groups ---------- If $\pi:E\rightarrow M$ has local trivialization, The transfer function only takes the value of the subgroup $H$ of $GL(n,\mathbb{R})$, Then the structural group of the vector bundle $E$ can be **reduced** to $H$. That is to say, for the general transfer function $g$, we hope to find the equivalent $g'$ that only takes the value of the better $H$. Generally, $H$ is a (special) orthogonal group and $GL^+(n,\mathbb{R}).$ whose determinant is positive. If it can indeed be reduced to $GL^+(n,\mathbb{R})$, then the vector bundle $E$ is said to be orientable**. It is called local trivialization **directional**, if $\det g_{\alpha\beta}>0$. Two directional trivializations are said to be **equivalent**, if $\phi_\alpha{\phi_\alpha'}^{-1}$Jacobian is positive. In this way, if $M$ is connected, all orientations of $E$ can be trivially divided into two equivalence classes, and each equivalence class is an orientation. A directional vector bundle with a given orientation is called a directional vector bundle. **Proposition 1.1**. *The structure group $E$ of a vector bundle of rank $n$ can always be reduced to $O(n)$. It can be reduced to $SO(n)$ if and only if $E$ can be oriented.* **Certificate:** The local inner product is induced through the natural frame, and then the unit decomposition is used to synthesize the global inner product. Then do Gram-Schimit orthogonalization to define a new orthogonal unit frame and give it a local trivialization. Calculation of vector bundles ---------- Let $E$ be a vector bundle of rank $n$, $\{(U_\alpha,\phi_\alpha)\}$ be a local trivialization, Transfer function $g_{\alpha\beta}$; $E'$ is a vector bundle of rank $m$, $\{(U_\alpha,\phi'_\alpha)\}$ is the local trivialization, and the transfer function $g'_{\alpha\beta}$. It can be assumed that the two open covers are the same because $\{(U_\alpha,\phi_\alpha)\}$ and $\{(U_{\alpha \beta},\phi_{\alpha})\}$ are equivalent, The open cover $\{U_{\alpha \beta}\}$ is intertwined with the open cover $\{U_\alpha\}$ and $\{U_\beta\}$. **Direct sum**: $E\oplus E'$ is a vector bundle of rank $n+m$, The local trivialization is $\{(U_\alpha, \phi_\alpha\oplus\phi_\alpha')\}$, The transfer function is $\begin{pmatrix} g_{\alpha\beta}&0\\ 0&g_{\alpha\beta}' \end{pmatrix}$ **Tensor product**: $E\otimes E'$ is a vector bundle of rank $nm$, The local trivialization is $\{(U_\alpha,\phi_\alpha\otimes\phi_\alpha')\}$, The transfer function is $g_{\alpha}\otimes g_{\alpha}'.$ $\operatorname{Hom}(E,E')$ is the entire cluster mapping from $E$ to $E'$, Isomorphic to $E^\ast \otimes E'.$ **Dual Bundle**: Recall that in functional analysis, $f:V\rightarrow W$ is a linear functional on a finite-dimensional space, $f^\ast :W^\ast \rightarrow V^\ast$ is a linear functional on the dual space, Its representation matrix is $f$, which represents the transpose of the matrix, so we also use $f^t$ to denote $f^\ast$. $E^\ast$ is the dual space of $E$, which is called the dual bundle. The local trivialization is $\{(U_\alpha,{(\phi^t_\alpha)}^{-1})\}$. Transfer function $(g_{\alpha\beta}^t)^{-1}$. **Pullback bundle**: Suppose $f:N\rightarrow M$ is a smooth map, then the vector bundle can be constructed: $\pi:f^{-1}E\rightarrow N$, is called the pullback bundle of $E$ from $f$. $f^{-1}E=\{(y,e)|f(y)=\pi(e)\}\subset N\times E.$ That is, for each point $y\in N$, Transplanting the fiber $E|_{f(y)}$ of $f(y)\in M$ is called $f^{-1}E|_{y}$. It is the only largest subset of $N\times E$, Such that $\pi \circ (f\times \mathrm{id}) =f\circ \operatorname{pr}_1$. The pullback bundle of the product bundle is the product bundle, so $f^{-1}E$ can be locally trivialized, The transfer function is $f^\ast g_{\alpha\beta}$. Homotopy of vector bundles --------------- **Theorem 1.1** (Homotopy property of vector bundles). *Suppose $Y$ is a compact manifold, $f_0,f_1:Y\rightarrow **Certificate:** Only need to prove $\,\forall\,t_0\in I$, $\,\exists\,\varepsilon>0$, $\,\forall\,t\in O(t_0,\varepsilon)$, $f_{t}^{-1}E\cong f_{t_0}^{-1}E$. From the compactness of $I$, the conclusion holds. Among them, $f:Y\times I\rightarrow X$ is the homotopy mapping between $f_0, f_1$, $f_t(y)=f(y,t)$. Take $\pi:Y\times I\rightarrow Y$ as the projection, Then $f^{-1}E|_{Y\times \{t_0\} }\cong\pi^{-1} f_{t_0}^{-1}E|_{Y\times \{t_0\} },$ That is, $f(y,t_0)$ is divided into two steps: $f_{t_0}(\pi(y,t_0)).$ Recall that $\operatorname{Hom}(f^{-1}E,\pi^{-1}f^{-1}_{t_0}E)$ is also a vector bundle, Each fiber is the ensemble of all linear maps; Take its subgroup $\operatorname{Iso}(f^{-1}E,\pi^{-1}f^{-1}_{t_0}E)$, Each fiber is an isomorphic whole within it. Therefore, we only need to give a cross section near $(Y,t_0)$. We take a local trivialization $\{(U_\alpha,\phi_\alpha)\}$ of $\operatorname{Hom}(f^{-1}E,\pi^{-1}f^{-1}_{t_0}E)$, Since $Y,I$ are compact, by the tubular neighborhood lemma (topology), $\,\exists\,Y\times O(t_0,\varepsilon)$ is contained by a finite number of $U_\alpha$, Make each $(y,O(t_0,\varepsilon))$ within a certain $U_\alpha$. Take the coordinate neighborhood $\{V_k\}$ of $Y$ to cover $Y$, Make $V_k\times O(t_0,\varepsilon)$ included in a certain $U_\alpha$. The section $s(y,t_0)$ has been defined globally on $Y$. Within each local trivialization neighborhood, Fiber on $V_k\times O(t_0,\varepsilon)$ of $\operatorname{Hom}(f^{-1}E,\pi^{-1}f^{-1}_{t_0}E)$, can be regarded as a Euclidean space, so that the section can be extended to the extension arbitrarily on it. That is, starting from $s(y,t_0)$, The continuation is $s(y,t)$, $(y,t)\in V_k\times O(t_0,\varepsilon).$ Further, Combine the extensions on each $V_k$ using the unit decomposition belonging to $\{V_k\}$, Forming an overall continuation on $Y\times O(t_0,\varepsilon)$, The cross section is thus defined as a whole within the strip area. When extending, please note that all non-isomorphic linear maps are closed sets, so we can extend them within open sets. The cross section is given, so the isomorphism is established near $t_0$.
