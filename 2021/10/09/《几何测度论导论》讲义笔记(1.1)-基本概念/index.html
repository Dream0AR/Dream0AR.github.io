external measure ------ Recall that the external measure $\mu$ on $X$ refers to the monotonic subadditive function of $2^X\rightarrow [0,\infty]$, Satisfies $\mu(\varnothing)=0.$ It is sometimes simply called a measure if it does not cause confusion. A set $A\subset X$ is said to be $\mu$-measurable if $\,\forall\,S\subset X,$ $\mu(S)=\mu(S\setminus A)+\mu(S\cap A).$ The latter is called the Caratheodory condition, It means that the set $A$ can cut other sets "$\mu$-additively". **Note 1.1**. *In fact, due to subadditivity, the condition is equivalent to $\mu(S)\ge\mu(S\setminus A)+\mu(S\cap A).$. From this, it is easy to prove that any $\mu$-zero test set is $\mu$-measurable.* Since $S\setminus A=S\cap (X\setminus A),$ It is easy to see that $A$ is $\mu$-measurable if and only if $X\setminus A$ is also. Assume $A_1,A_2$ are $\mu$-measurable, then $\,\forall\,S\subset X,$ $$\begin{aligned} \mu(S)=&\mu(S\setminus A_1)+\mu(S\cap A_1)& A_1\text{是$\mu$-可测的}\\ =&\mu((S\setminus A_1)\setminus A_2)+\mu((S\setminus A_1)\cap A_2)+\mu(S\cap A_1)& A_2\text{是$\mu$-可测的}\\ \ge&\mu(S\setminus (A_1\cup A_2))+\mu(S\cap((A_2\setminus A_1)\cup A_1))& \text{次可列可加性}\\ =&\mu(S\setminus(A_1\cup A_2))+\mu(S\cap(A_1\cup A_2)), \end{aligned}$$ Thus $A_1\cup A_2$ is $\mu$-measurable. Then $X\setminus((X\setminus A_1)\cup (X\setminus A_2))=A_1\cap A_2$ is also $\mu$-measurable, $A_2\setminus A_1=A_2\cap (X\setminus A_1)$ is the same. It can be concluded by induction that the finite-step union, intersection, and complement operations all maintain $\mu$-measurable properties. The Caratheodory condition confers additivity to disjoint $\mu$-measurable sets: **Lemma 1.2** (Listable additivity). *If $A_1,\cdots$ is a disjoint $\mu$-measurable set, then $\,\forall\,S\subset X,$ $\mu(S\cap \bigcup_{i=1}^\infty A_i)=\sum_{i=1}^\infty\mu(S\cap A_i). $* **Proof:** Additivity can be listed by times, $\mu(S\cap \bigcup_{i=1}^\infty A_i)\le \sum_{i=1}^\infty\mu(S\cap A_i).$ By the Caratheodory condition, $\,\forall\,S\subset X,$ $\mu(S\cap (A_1\cup A_2))=\mu((S\cap (A_1\cup A_2))\setminus A_1)+\mu(S\cap(A_1\cup A_2)\cap A_1)= \mu(S\cap A_1)+\mu(S\cap A_2).$ This can be summarized into the case of a finite number of unintersecting $\mu$-measurable sets. Existing $\sum_{i=1}^n \mu(S\cap A_i)=\mu(S\cap\bigcup_{i=1}^n A_i)\le \mu(S\cap \bigcup_{i=1}^\infty A_i).$ Let $n\rightarrow\infty,$ get the inequality in the other direction, and thus the proposition is proved. **Lemma 1.3**. *If $A_1,\cdots$ is an increasing $\mu$-measurable set, then $\,\forall\,S\subset X,$ $\mu(S\cap \bigcup_{i=1}^\infty A_i)=\lim\limits_{i}\mu(S\cap A_i).$* **Certificate:** Remember $A_0=\varnothing,$ Since $\bigcup_{i=1}^\infty A_i=\bigcup_{i=1}^\infty (A_i\setminus A_{i-1}),$ By listability and additivity, $$\begin{aligned} \mu(S\cap \bigcup_{i=1}^\infty A_i)&=\mu(S\cap \bigcup_{i=1}^\infty (A_{i}\setminus A_{i-1}))\\ &= \sum_{i=1}^\infty \mu(S\cap (A_i\setminus A_{i-1}))\\ &=\lim\limits_n \sum_{i=1}^n \mu(S\cap (A_i\setminus A_{i-1}))\\ &=\lim\limits_{n}\mu(S\cap A_n), \end{aligned}$$ The proposition is proved. **Corollary 1.4**. *Suppose $A_1,\cdots$ is a decreasing $\mu$-measurable set. If $\,\exists\,A_k$ has limited measure, then $\,\forall\,S\subset X,$ $\mu(S\cap \bigcap_{i=1}^\infty A_i)=\lim\limits_{i}\mu(S\cap A_i).$* The set $\mathcal{S}$ of a series of subsets of $X$ is called $\sigma$-algebra, if: (1) $\varnothing,X\in \mathcal{S};$ (2) $A\in \mathcal{S}\Rightarrow X\setminus A\in \mathcal{S};$ (3) $A_1,\cdots \in \mathcal{S}\Rightarrow \bigcup_{i=1}^\infty A_i\in \mathcal{S}.$ **Note 1.5**. *$\sigma$-algebras are closed to listable unions and complement operations. It is easy to see that it is also closed to listable intersections. Since the intersection of $\sigma$-algebras is still a $\sigma$-algebra, the smallest $\sigma$-algebra that contains a series of specified sets can be found. In particular, for the topological space $X,$ The smallest $\sigma$-algebra containing all open sets is called a Borel algebra in $X$, where the set is called a Borel set.* **Lemma 1.6**. *The ensemble of $\mu$-measurable sets constitutes a $\sigma$-algebra, including all $\mu$-zero measurable sets of $X$.* **Proof:** Just prove that if $A_1,\cdots$ is $\mu$-measurable, Then $\bigcup_{i=1}^\infty A_i$ is also. Let $B_i=\bigcup_{j=1}^i A_j$ be an increasing $\mu$-measurable set, Then $\,\forall\,S\subset X,$ $$\begin{aligned} \mu(S)&=\mu(S\setminus \bigcup_{i=1}^n A_i)+\mu(S\cap \bigcup_{i=1}^n A_i)\\ &\ge\mu(S\setminus \bigcup_{i=1}^\infty A_i)+\mu(S\cap B_n). \end{aligned}$$ Let $n\rightarrow \infty,$ that is $$\begin{aligned} \mu(S)&\ge \mu(S\setminus \bigcup_{i=1}^\infty A_i)+ \mu(S\cap \bigcup_{n=1}^\infty B_n)\\ &= \mu(S\setminus \bigcup_{i=1}^\infty A_i)+\mu(S\cap \bigcup_{i=1}^\infty A_i), \end{aligned}$$ Thus the proposition is proved. Borel regular measure ------------- An external measure $\mu$ is said to be **regular** if $\,\forall\,A\subset X,$ There exists a $\mu$-measurable set $B\supset A$ satisfying $\mu(B)=\mu(A).$ At this time, the previous property that $A_i$ is a monotonic column no longer needs to be assumed that $A_i$ is $\mu$-measurable. When $X$ is a topological space, The external measure $\mu$ is **Borel regular** if all Borel sets are $\mu$-measurable, And $\,\forall\,A\subset X,$ exists Borel set $B\supset A$ such that $\mu(B)=\mu(A).$ It should be emphasized that $\mu(B)=\mu(A)$ does not mean $\mu(B\setminus A)=0,$ Unless $A$ is $\mu-$ measurable and $\mu(A)<\infty.$ **Note 1.7**. *Recall that the Borel measure $\mu_0$ is the mapping of the entire Borel set to $[0,\infty]$, satisfying $\mu_0(\varnothing)=0$ and listable additivity (thereby implying monotonicity). At this time, $\,\forall\,A\subset Given any subset $Y\subset X$ and external measure $\mu,$, a new external measure $\mu |_Y,$ can be defined $\mu|_Y(Z):=\mu(Y\cap Z),$ $Z\subset X.$ Any $\mu$-measurable set is $\mu|_Y$-measurable, even if $Y$ itself is not necessarily $\mu$-measurable. When $Y$ is $\mu$-measurable and $\mu(Y)<\infty$, if $\mu$ is Borel regular, Then $\mu|_Y$ is also. For this point, just use the Borel regularity of $\mu$ to select the appropriate $B_1\supset Y,$ $B_2\supset B_1\setminus Y,$ $B_3\supset A\cap Y.$ Then $A\subset (X\setminus B_1)\cup B_2\cup B_3$ and both $\mu|_Y$ have the same measure. When $X$ is a metric space, for $A,B\subset X,$ Remember $d(A,B)=\inf\{d(a,b):a\in A,b\in B\}.$ $\inf\varnothing:=+\infty.$ **Theorem 1.8** (Caratheodory discriminant method). *Suppose $(X,d)$ is the metric space and $\mu$ is the external measure. If $\mu(A\cup B)=\mu(A)+\mu(B),$ $\,\forall\,A,B\subset X$ satisfies $d(A,B)>0,$, then all Borel sets are $\mu$-measurable.* **Proof:** Just prove that all closed sets are $\mu$-measurable. $\,\forall\,$ closed sets $C\subset X,$ Take $C_j=\{x\in X:d(x,C)\le \frac{1}{j}\}.$ then $\,\forall\,S\subset X,$ $d(S\setminus C_j,S\cap C)>0.$ Thus there is $$\mu(S)\ge \mu(S\setminus C_j)+\mu(S\cap C),\quad \,\forall\,j>0.$$ Let $j\rightarrow \infty,$ Since $S\setminus C_j=S\cap (X\setminus C_j),$ $X\setminus C_j$ single increase, Thus $\lim\limits_{j\rightarrow \infty}\mu(S\setminus C_j)=\mu(S\setminus \bigcap_{j}C_j)=\mu(S\setminus C).$ The last equal sign is because $C$ is a closed set, so all points with a zero distance from $C$ are in $C$. Therefore $$\mu(S)\ge \mu(S\setminus C)+\mu(S\cap C),$$ and thus any closed set $C$ is measurable, The proposition is proved. **Definition 1.9**. *The Borel regular measure $\mu$ is said to be **open**$\sigma$**-finite**, if $X=\bigcup_j V_j,$ $V_j$ is an open set and the measure is finite.* Obviously, when $X$ is a separable metric space and $\mu$ is locally finite, it is open $\sigma$-finite. **Theorem 1.10**. *Assume that each closed set in the topological space $ $ $$\mu(A)=\inf_{\text{开集}U\supset A}\mu(U).$$* *If $A$ is $\mu$-measurable, then there is $$\mu(A)=\sup_{\text{闭集}C\subset A}\mu(C).$$* **Idea:** Discuss the situation where the whole space measure is finite/infinite. Take the total set that makes the conclusion true, Prove that it contains $\sigma$-algebras, which in turn contain all open sets, and thus contain the entire Borel algebra. Finally, the conclusion is drawn from regularity. **Proof:** First assume that $\mu(X)<\infty,$ then $(1)\Rightarrow (2).$ Since the measure is Borel regular, we only need to prove that $A$ is a Borel set. Take $\mathcal{A}:=\{\text{Borel set}A\subset X:\text{(1) is established}\},$ Then $\mathcal{A}$ naturally contains all open sets. Take $A_1,\cdots\in \mathcal{A}.$ $\,\forall\,\varepsilon>0,$ $\,\exists\,$ open $U_1,\cdots,$ satisfying $U_j\supset A_j,$ And $\mu(U_j\setminus A_j)\le 2^{-j}\varepsilon.$ Then $$\mu(\bigcup_j U_j \setminus \bigcup_j A_j),\mu(\bigcap_j U_j\setminus \bigcap_j A_j)\le \sum_j\mu(U_j\setminus A_j)\le \varepsilon,$$ Thus $\bigcup_j A_j,\bigcap_j A_j\in \mathcal{A},$ set pairs can be merged, Intersectable and closed. Since any closed set is an open set and can be intersected, all closed sets are in $\mathcal{A}$. Take $\widetilde{\mathcal{A} }:=\{A\in \mathcal{A}:X\setminus A\in \mathcal{A}\},$ Then it is easy to verify that $\widetilde{\mathcal{A} }$ is a $\sigma$-algebra containing all open sets, Therefore, $\mathcal{A}$ contains (that is, is) the entire Borel set, and it is proved that $\mu(X)$ is finite. For the case $\mu(X)=\infty$, just use the $\sigma$-finiteness of $X$, Take $X=\bigcup_{j} V_j,$ Each $V_j$ has a finite measure. At this time $\mu|_{V_{j} }(X)<\infty,$ Applying the previous conclusion, $\,\forall\,\varepsilon>0,$ There is an open set $U_j\supset A$ that satisfies $\mu(U_j\cap V_j\setminus A)\le2^{-j}\varepsilon,$ Thus $\mu(\bigcup_{j}(U_j\cap V_j)\setminus A)\le \varepsilon.$ Since $\bigcup_j (U_j\cap V_j)$ is an open set containing $A$, (1) holds. For (2), similarly $\,\forall\,\varepsilon>0,$ There is a closed set $C_j\subset A$ that satisfies $\mu(A\cap V_j\setminus C_j)\le 2^{-j}\varepsilon.$ Then $$\mu(A\setminus \bigcup_j C_j)=\mu( A\cap \bigcup_jV_j\setminus \bigcup_jC_j)\le \sum_j \mu(A\cap V_j\setminus C_j) \le \varepsilon.$$ Thus when $\mu(A)=\infty$, $\mu(\bigcup_{j=1}^NC_j)\rightarrow \infty;$ When $\mu(A)<\infty$, For sufficiently large $N$, there is $\mu(A\setminus \bigcup_{j=1}^N C_j)\le 2\varepsilon.$ Therefore (2) is proved. **Note 1.11**. *Note that if $ From the above theorem, Lusin’s theorem can be proved: **Theorem 1.12** (Lusin). *Let $\mu$ be the Borel canonical outer measure, and all closed sets in the topological space $X$ are intersections of open sets that can be listed (for example, $X$ can take a metric space). Let $A$ be a $\mu$-measurable set with limited measure, and $f:A\rightarrow \mathbb{R}$ be a measurable function. Then $\,\forall\,\varepsilon>0,$ exists a closed set $C\subset A,$ in $X$ such that $\mu(A\setminus C)<\varepsilon,$ and $f|_C$ is continuous.* **Proof:** Take $A_{ij}=f^{-1}[\frac{j-1}{i},\frac{j}{i}),$ $i\in \mathbb{Z}_+,$ $j\in \mathbb{Z}.$ Then $\mu$-measurable $A_{ij}$ has no intersection, and the measure is limited. And $\bigcup_{j}A_{ij}=A$ holds for any $i$. Since $\mu|_{A}$ is Borel regular, Applying the above theorem, we can find the closed set $C_{ij}\subset A_{ij},$ in $X$ $\mu(A_{ij}\setminus C_{ij})=\mu|_A(A_{ij}\setminus C_{ij})<2^{-i-|j|-2}\varepsilon.$ Further$\mu(A\setminus \bigcup_j C_{ij})< 2^{-i}\varepsilon,$ Therefore for each $i,$ There is $J(i)\in \mathbb{Z}_+$ such that $\mu(A\setminus \bigcup_{|j|\le J(i)}C_{ij})\le 2^{-i}\varepsilon.$ Take $C=\bigcap_{i}\bigcup_{|j|\le j(i)}C_{ij}$ as a closed set, Then $\mu(A\setminus C)\le \varepsilon.$ Finally, define $g_i:\bigcup_{|j|\le J(i)}C_{ij}\rightarrow \mathbb{R},$ $g_i|_{C_{ij} }(x)=\frac{j-1}{i}.$ Since $i is fixed, $ $C_{ij}$ have no intersection with each other, Therefore $g_i|_C$ is continuous. Since $\,\forall\,x\in C,$ $0\le f(x)-g_i(x)\le \frac{1}{i},$ Therefore $g_{i}|_C\rightrightarrows f|_C,$ Thus $f|_C$ is continuous. The article was last updated on 2021-10-09 13:26:19
