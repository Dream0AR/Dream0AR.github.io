《微分流形》第二章-切丛(1) "Differential Manifolds" Chapter 2-Tangential Cluster (1)

cut space ------ Recall that we can define $C^\infty$ curve $C:(a,b)\rightarrow M,$ $C(t_0)=p.$ $C_p^\infty$ represents the entire function of $M$ at $p$ point $C^\infty$, That is, the elements are all smooth functions on a certain neighborhood of point $p$. The function on $C_p^\infty$ can perform operations, But operations can only be performed on common neighborhoods. The "tangent vector" of curve $C(t)$ at point $p$ points to the directional derivative operator $X:C_p^\infty\rightarrow \mathbb{R},$ $X(f)=\frac{df\circ c(t)}{dt}|_{t=t_0},$ satisfies: (1) $X(af+bg)=aX(f)+bX(g);$ (2) $X(fg)=X(f)g(p)+f(p)X(g).$ Let $T_pM:=\{X\text{be the tangent vector}\} of the curve passing}p\text{,$ It is called the tangent space of $M$ at $p$. $\widetilde{T}_pM:=\{\widetilde X:C_p^\infty\rightarrow \mathbb{R}\text{Satisfies (1), (2)}\}.$ Then there are $T_pM\subset \widetilde{T}_pM.$ $\widetilde{T}_pM$ can introduce addition, Multiplying numbers makes it a vector space. Recall that for the coordinate card $(U,\varphi), $ $\varphi$ is a smooth homeomorphism between manifolds. For $\varphi^{-1},$ only let $x^i$ change, That is, the smooth curve $\varphi^{-1}(\cdots,x^i,\cdots),$ is obtained, which is called $x^i$-curve. There are $m$ coordinate curves passing through each point $q\in U$. Use $\left(\frac{\partial {} }{\partial {}x^i}\right)_p$ to represent $x_i$-the curve tangent vector $X_i,$ at $p$ $X_i(f)=\frac{d}{dx^i}[f\circ \varphi^{-1}(\cdots, x^i,\cdots)]_{\varphi(p)}=[\frac{\partial {} }{\partial {}x^i}(f\circ\varphi^{-1})]_{\varphi(p)}.$ $f\circ\varphi^{-1}:\varphi(U)\rightarrow \mathbb{R}.$ Thus $\left(\frac{\partial {} }{\partial {}x^i}\right)_p\in T_pM,$ $1\le i\le m.$ **Proposition 1.1**. *$T_pM$ is an $m$-dimensional vector space. $\{X_i\}$ constitutes a set of basis of $T_pM$.* **Certificate:** Take any $X\in T_pM,$ $C:(a,b)\rightarrow M,$ $C(t_0)=p.$ $C'(t_0)=X.$ $\varphi\circ C(t)=(x^i(t))$ is called **parametric equation**. By definition, $X(f)=\frac{d}{dt}[f\circ C(t)]|_{t=t_0}=\frac{d}{dt}[(f\circ\varphi^{-1})(\varphi\circ C(t))]|_{t_0}=\sum_{i=1}^m \frac{dx^i(t)}{dt}|_{t_0}\cdot [\frac{\partial {} }{\partial {}x^i}(f\circ \varphi^{-1})]_{\varphi(p)}.$ Remember $a^i=\frac{d x^i}{dt}|_{t_0},$ then $X(f)=\sum_{i=1}^m a^i X_i(f),$ Thus $X=\sum_{i=1}^m a^i X_i.$ Let $\sum_{i=1}^m b^i X_i,$ To find the point where $C(t)$ passes $p$, make $\frac{dx^i(t)}{dt}|_{t_0}=b^i.$ Let $\varphi(p)=(d^i),$ take $x^i(t)=d^i+b^i(t-t_0),$ $C(t)=\varphi^{-1}(x^i(t))$ is enough. Then $C'(t_0)=\sum_i b^iX_i.$ It can then be shown that $T_pM$ is a vector space. It only needs to be explained that $\{X_i\}$ is linearly independent. Suppose $\sum_{i=1}^m a^i X_i=0,$ Take $m$ pieces of $f=x^i:=\pi^i\circ \varphi$ that only grow in the direction of $x^i$ to test, It can be explained that $a^i\equiv 0.$ and $T_pM$ is an $m$-dimensional vector space. **Note 1.2**. *In fact, there is $T_pM=\widetilde{T}_pM.$* As mentioned before, the zero element in $C_p^\infty$ is not unique, so it is not a vector space. For this purpose, the equivalence relationship $f\sim g$ $\Leftrightarrow$ $\,\exists\,p$ point neighborhood $W,$ can be defined $f|_W=g|_W.$ The quotient space $\mathcal{F}_p^\infty=C_p^\infty/\sim$ is a vector space, It is called **Function Bud Space**. There is an induced $X on it:\mathcal{F}_p^\infty\rightarrow \mathbb{R},$ That is, $X([f]):=X(f),$ $[f](p):=f(p).$ It also satisfies properties similar to (1) and (2). cotangent space -------- Let $V$ be an $m$ dimensional vector space, $V^\ast =\{\text{linear }\omega:V\rightarrow \mathbb{R}\}$ is also an $m$-dimensional vector space, Taking the dual basis as the basis. For the $m$-dimensional smooth manifold $M^m, $ $T_pM$ is the tangent space, $T_p^\ast M$ represents its dual space, which is called the **cotangent space** of $M$ at $p$. $X\in T_pM,$ $f\in C_p^\infty$ has directional derivative $X(f).$ Consider fixing $f$ and let $X$ change, Remember $\omega_f(X)=X(f),$ Then $\omega_f:T_pM\rightarrow \mathbb{R}$ is a linear function, in $T_p^\ast M$. Let $\omega_f$ be $(df)_p, and $ is called the **differential** of $f$ at point $p$. Take any coordinate system $(U,\varphi),$ containing $p$, then $\{(dx^i)_p\}\in T_p^\ast M,$ is the dual basis of $\{X_i\}$, so it constitutes the basis of $T_p^\ast M$, which is called **natural basis**. $\,\forall\,f\in C_p^\infty,$ $(df)_p=\sum_{i=1}^m a_i(dx^i)_p\in T_p^\ast M.$ Both sides act on $X_j,$ Obtain $X_j(f)=a_j.$ Therefore there is $(df)_p=\sum_{i=1}^m X_i(f)(dx^i)_p.$ From this we can also see the reason why it is called differential. **Note 1.3**. *If $f\sim g\in C_p^\infty,$ then $X(f)=X(g),$ and thus $(df)_p=(dg)_p.$ Then note $\tau:\mathcal{F}_p^\infty\rightarrow T_p^\ast M,$ $\tau([f])=(df)_g$ is linearly satisfied. $\widehat{\tau}:\mathcal{F}_p^\infty/\ker(\tau)\cong T_p^\ast M$ is a linear isomorphism, $\ker(\tau)=\{[f]\in \mathcal{F}_p^\infty|\tau([f])=(df)_p=0\}.$ Therefore, another way to define the cotangent space is to create the quotient space of the function bud space, and then define the tangent space dually.* Qie Cong ---- Let $TM=\bigcup_{p\in M}T_pM,$ be called the tangent bundle of $M$. Introduce $\pi:TM\rightarrow M,$ $\pi(T_pM)\rightarrow p,$ is called **natural projection**. Take any coordinate card $(U,\varphi; x^i),$ and examine $\pi^{-1}(U).$ $\,\forall\,q\in U,$ $T_qM$ has a natural basis, so $T_qM\cong \mathbb{R}^m.$ Thus there is $$\widehat{\Phi}:\pi^{-1}(U)\xrightarrow{\Phi}U\times \mathbb{R}^m\xrightarrow{ \varphi\times \mathrm{id}_{\mathbb{R}^m} }\varphi(U)\times \mathbb{R}^m,$$ Among them $\Phi(X)=(\pi(X),\xi),$ $X=\sum_{i=1}^m \xi^i X_i.$ Give $TM$ a natural topological structure such that $\pi^{-1}(U)$ is an open subset of $TM$, And $\widehat\Phi:\pi^{-1}(U)\rightarrow \varphi(U)\times \mathbb{R}^m$ is a homeomorphism. Let all open subsets of $\pi^{-1}(U_i)$ form the topological basis for generating $TM$. Then $TM$ becomes a $2m$ dimensional topological manifold. At this time $\widehat{\mathcal{F} }=[\{(\pi^{-1}(U_\alpha),\widehat{\Phi}_\alpha)\}]$ is the $TM$ coordinate atlas, The transfer function $\widehat{\Phi}_\beta\circ \widehat{\Phi}_\alpha^{-1}(x,\xi)=(\varphi_{\beta}\circ\varphi_{\alpha}^{-1}(x),J(\varphi_\beta\circ\varphi_\alpha^{-1})\xi)$ is a smooth function, Therefore, the atlas is smooth, so the tangent bundle $TM$ is a $2m$-dimensional $C^\infty$ manifold.
