overall angular form ---------- On an oriented manifold $M$, the highest-order form is **positive** if it is in the oriented class of $M$. Take $\sigma\in H^{n-1}(S^{n-1})$ as the generator, $p:\mathbb{R}^n-\{0\}\rightarrow S^{n-1}$ is deformation shrinkage, It is stipulated that $\sigma$ is positive on $S^{n-1}$ if and only if $dr\wedge p^\ast \sigma$ is positive on $\mathbb{R}^n-\{0\}$. Suppose $\sigma$ is the upper positive form of $S^{k-1}$, and $\int_{S^{k-1} }\sigma=1$, Then $\psi=p^\ast \sigma$ is called the **angular form** on $\mathbb{R}^k-0$. $[\psi]\in H^{k-1}(\mathbb{R}^k-\{0\})$ is the generator. Let $\rho(r)\in C^\infty[0,+\infty)$, $\rho(r)=\begin{cases} -1&r\le \delta_1\\ 0&r\ge \delta_2 \end{cases}$, $\delta_1<\delta_2$, the middle part is smoothly connected. $d\rho=\rho'(r)dr$ is a bump-1 form. At this time, $[d\rho\wedge \psi]\in H_c^k(\mathbb{R}^k)$, dig out $B_\varepsilon$, Using $\rho$ properties and Stokes theorem, it can be proved that $\int_{\mathbb{R}^k}d\rho\wedge \psi=1$. That is, $[d\rho\wedge \psi]$ is the generator. Consider the $k$ directed vector bundle $\pi of rank $M$:E\rightarrow M$, $E^0=E-s(E)$, $s$ is the zero cross-section. Let $\left<{},\right>$ be the metric, for the vector $v$ on each fiber, Define $r(v)=\sqrt{\left<{}v,v\right>}$. Then $r$ is meaningful on $E$, $\rho(r)$ can be regarded as a function defined on $E$. A $k-1$-form $\psi$ of $E^0$ is called **global angular form**, If $\psi$ is limited to each fiber $E_x^0\simeq \mathbb{R}^k-\{0\}$, it is an angular form, And $d\psi$ can be naturally extended into a $k$-form of $E$. If there is a global angular form $\psi$ on $E^0$, Then the Thom class of $E$ is $\Phi=d\rho\wedge\psi+\rho d\psi$. This is because the second term disappears on the fiber, and the first term integrates $1$. Explicit representation of Euler classes for planar bundles ----------------------- Assume that $E$ is an oriented planar bundle, that is, the rank is $2$. Taking the coordinate atlas and directional trivialization, There are coordinates $(x_1^\alpha,...,x_n^\alpha)$ on $U_\alpha$. Using directional trivialization, define the polar coordinate $r_\alpha$ of $E^0|_{E_\alpha}$, $\theta_\alpha$, thus there are coordinates $\pi^\ast x^\alpha, r_\alpha, \theta_\alpha$. Assume that the upper metric of $E$ preserves the inner product, that is, the transfer function is reduced to $SO(2)$, then $r_\alpha=r_\beta$, We define the global $r$. In fact this is the previous $r(v)=\sqrt{\left<{}v,v\right>}$. But $\theta_\alpha,\theta_\beta$ differ by one rotation, $\varphi_{\alpha\beta}$ can be defined, Such that $\theta_\beta=\theta_\alpha+\pi^\ast \varphi_{\alpha\beta}$. In the sense of $\mod 2\pi$, $\varphi_{\alpha\beta}$ satisfies the cocycle condition and can be uniquely defined. Therefore, if de Rham cohomology is adopted, then $\{d\varphi_{\alpha\beta}\}$ satisfies the cocycle condition. Definition $\xi_\alpha=\frac{1}{2\pi} \sum_\gamma \rho_\gamma d\varphi_{\gamma\alpha}$, Then on $U_{\alpha\beta}$, $\frac{1}{2\pi}d\varphi_{\alpha\beta}=\xi_\beta-\xi_\alpha$. Therefore, $d\xi_\alpha=d\xi_\beta$, can be put together to define the overall $2$-form $e$: $e|_{U_\alpha}=d\xi_\alpha$. Obviously $de=0$. Assert that $[e]\in H^2(M)$ has nothing to do with $\{\xi_\alpha\}$ selection, Called the **Eulerian class** of the plane bundle $E$, also denoted $e(E)$. The selection is irrelevant because if there is another $\tilde \xi_\alpha$ that meets the requirements, Then $\tilde \xi_\alpha-\xi_\alpha$ will satisfy the compatibility and can be defined as $\eta$ as a whole. Then $d\eta=d\tilde\xi_\alpha-d\xi_\alpha$, so they are equal at the cohomology level. If $E$ is given a directional trivialization, assuming it is reduced to $SO(2)=SU(1)$, Then $\varphi_{\alpha\beta}=-\frac{1}{i}\log g_{\alpha\beta}$, further $e|_{U_\alpha}=d\xi_\alpha=-\frac{1}{2\pi i}\sum_\gamma d(\rho_\gamma \cdot d\log g_{\gamma\alpha})$, It is called the explicit representation formula of the Euler class of plane bundles. When $E$ is a product bundle, the transfer function is a constant matrix, so the Euler class is zero. It reflects the degree of distortion of the directed vector bundle $E$. From the expression formula, the functor property of the Euler class can be proved: **Proposition 1.1**. *$f:N\rightarrow M$ is a smooth map, $\pi:E\rightarrow M$ is a rank-2 directed vector bundle, then $e(f^{-1}E)=f^\ast e(E)\in H^2(N)$.* Display representation of planar bundle Thom class ----------------------- $\frac{d\theta_\alpha}{2\pi}-\pi^\ast \xi_\alpha$ defines the $1$-form $\psi$ on $E^0$. The $\psi$ limit on each fiber $E_x^0$ is $\frac{d\theta_\alpha}{2\pi}$, It is the angular form of $E_x^0$; at the same time, $d\psi=-\pi^\ast e$ is defined on $E$, and $\psi$ is the overall angular form. Therefore, the Thom class of $E$ is $\Phi=d\rho(r)\wedge \psi-\rho(r)\pi^\ast e$. If $s:M\rightarrow E$ is zero cross-section, then $s^\ast \Phi=e$. That is, zero cross section pulls the Thom class back to the Euler class. Using explicit representations of Euler classes, That is, $\Phi=d\rho(r)\wedge \frac{d\theta_\alpha}{2\pi}+\frac{1}{2\pi i}d(\rho(r)\pi^\ast \sum_\gamma\rho_\gamma d\log g_{\gamma\alpha})$.
