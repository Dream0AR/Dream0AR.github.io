《微分流形》第二章-切丛(2) "Differential Manifolds" Chapter 2-Tangential Cluster (2)

Qie Cong ---- Recall that $M^m$ is an $m$-dimensional $C^\infty$ manifold, There is a tangent bundle $TM=\bigcup_{p\in M}T_pM\xrightarrow{\pi}M,$ with natural topology. $T_qM$ has natural basis $\{X_i\},$ $T_qM\cong \mathbb{R}^m,$ Thereby we have homeomorphism$\Phi_U:\pi^{-1}(U)\rightarrow U\times \mathbb{R}^m\rightarrow \varphi(U)\times \mathbb{R}^m.$ $\{(\pi^{-1}(U_\alpha),\Phi_\alpha)\}$ is the smooth coordinate atlas of $TM$, Make it a $2m$-dimensional $C^\infty$ manifold. vector field ------ $X:p\mapsto X_p\in T_pM$ is called the **vector field** on $M$. The folio set $U\subset M,$ $X:U\ni p\mapsto T_pM$ is called the vector field on $U$. $X$ can also be described as $X:M\rightarrow TM,$ $\pi\circ X=\mathrm{id}_M.$ If $X$ is also a $C^\infty$ mapping between manifolds, then $X$ is said to be a $C^\infty$ vector field on $M$. Consider pulling back locally to $\widehat{X}:\varphi(U)\rightarrow \varphi(U)\times \mathbb{R}^m$, The specific expression is $x\mapsto (x,\xi\circ\varphi^{-1}(x)).$ Therefore, we only need to consider whether $\xi\circ\varphi^{-1}$ is smooth, That is, whether each component of $\xi$ is in $C^\infty(U)$. Use $\chi(M)$ to represent the entire $M$ mountain smooth vector field, $\,\forall\,X,Y\in \chi(M),$ $f,g\in C^\infty(M),$ then $fX+gY\in \chi(M),$ $(fX+gY)(p):=f(p)X(p)+g(p)Y(p)\in T_pM.$ This is because $C^\infty(U)$ is the same as $C^\infty(\mathbb{R}^m)$, They are all multiplicatively closed vector spaces, so just consider local representation. In particular $\chi(M)$ is an infinite-dimensional vector space. Recall that if $f\in C^2(U),$ $U\subset \mathbb{R}^m, the mixed partial derivatives of $ $f$ can exchange order. Then for general vector fields, we consider whether $XY=YX,$ $X,Y\in\chi(M).$ That is, whether $[X,Y]f=XYf-YXf$ always takes zero. Here $[-,-]:\chi(M)\times \chi(M)\rightarrow\chi(M)$ is called the **Lie bracket** of $X$ and $Y$. $[X,Y]_p f=X_pYf-Y_pXf.$ Recall $(Yf)(p)=Y_p(f),$ hope $Yf\in C^\infty(M).$ Examine $(Yf)\circ\varphi^{-1},$ $(Yf)|_U=\sum_i\eta^i X_i(f),$ Then $(Yf)\circ\varphi^{-1}=\sum_i \eta^i\circ\varphi^{-1}\cdot \frac{\partial f\circ\varphi^{-1} }{\partial x_i}\in C^\infty(\mathbb{R}^m).$ Therefore $X_pYf$ is meaningful, there are: $$\begin{aligned} X_pYf&=\sum_i \xi^i(p)\sum_j X_i(\eta^jX_j(f))\\ &=\sum_{i,j} \xi^i(p)X_i(\eta^j)X_j(f)+\xi^i(p)\eta^j(p)X_iX_j(f) \end{aligned}$$ Swap the order of $X,Y$ to get $Y_pXf,$ thus: $$[X,Y]_pf=\sum_{i,j}[\xi^i(p)X_i(\eta^j)-\eta^i(p)X_i(\xi^j)]X_j(f)+\sum_{i,j}\xi^i(p)\eta^j(p)[X_i,X_j] (f),$$ The latter term is zero due to $f\in C^\infty(M)$, Therefore $[X,Y]|_U=\sum_{ij} [\xi^iX_j(\eta^j)-\eta^i X_i(\xi^j)]X_j,$ $[X,Y]\in\chi(M)$ is indeed a smooth vector field. It can be seen that $[-,-]$ satisfies the following properties: - Anti-commutativity: $[X,Y]=-[Y,X];$ - Linearity: $[aX_1+bX_2,Y]=a[X_1,Y]+b[X_2,Y];$ - Jacobi identity: $[[X,Y],Z]+[[Y,Z],X]+[[Z,X],Y]=0.$ Therefore $\chi(M)$ is a **Lie algebra**. cut reflection ------ Let $F:M^m\rightarrow N^n$ be the $C^\infty$ mapping between $C^\infty$ manifolds. $\,\forall\,$Curve through point $p$$C(t),$ $C(t_0)=p,$ $C'(t_0)=X,$ Then corresponding to the curve $F(C(t)) passing $q$, the tangent vector is $Y.$ This induces a mapping between tangent spaces ${F_\ast }_p:T_pM\rightarrow T_qN.$ $\,\forall\,f\in C_q^\infty(N),$ $Yf=X(f\circ F).$ That is ${F_\ast }_pX(f)=X(f\circ F).$ Easy to prove ${F_\ast }_p(aX_1+bX_2)=a{F_\ast }_pX_1+b{F_\ast }_pX_2,$ Therefore ${F_\ast }_p$ is a linear mapping. Recall that linear mappings between vector spaces $\varphi:V\rightarrow W$ induce dual mappings $\varphi^\ast :W^\ast \rightarrow V^\ast ,$ Defined as $\,\forall\,w^\ast \in W^\ast ,$ $(\varphi^\ast w^\ast )(v)=w^\ast (\varphi (v)).$ The dual mapping is also linear, which is called **pullback mapping**. Therefore, for the above ${F_\ast }_p,$ There is pullback reflection$F^\ast :T_q^\ast N\rightarrow T_p^\ast M,$ $F^\ast (df)_q(X)=(df)_q({F_\ast }_pX)={F_\ast }_pX(f)=X(f\circ F)= d(f\circ F)_p(X),$ That is $F^\ast (df)_q=d(f\circ F)_p.$ **Proposition 1**. *Suppose $F\in C^\infty(M,N),$ $G\in C^\infty(N,W),$ then ${(G\circ F)_{\ast } }_p={G_{\ast } }_q\circ {F_\ast }_p,$ $(G\circ F)^\ast =F^\ast \circ G^\ast . $ And if $F$ is a smooth homeomorphism, then ${F_\ast }_p$ is a linear isomorphism, $\,\forall\,p\in M.$* The former properties are easy to explain, while the latter properties use $F^{-1}\circ F=\mathrm{id}_M,$ $F\circ F^{-1}=\mathrm{id}_N,$ can be obtained by combining the previous properties. **Proposition 2**. *Suppose $F:M\rightarrow N$ is a smooth mapping, $q=F(p).$ Then ${F_\ast }_pX_i=\sum_\alpha [X_i(y^\alpha \circ F)]Y_\alpha,$ $F^\ast (dy^\alpha)_q=\sum_i [X_i(y^\alpha\circ F)] (dx^i)_p.$* Just verify according to the definition. Note that $X_i(y^\alpha\circ F)=J(\psi\circ F\circ \varphi^{-1})_{\alpha,i},$ Therefore the cut mapping is a generalization of the Jacobi matrix. Give the following definition: - Define the **rank** of $F$ at point $p$ to be the rank of ${F_{\ast } }_p$$=r(D\widehat{F})_{\varphi(p)},$ Denoted as $r({F_\ast }_p);$ - If ${F_\ast }_p$ is injective, that is, $r({F_\ast }_p)=m,$, then $F$ is said to be **immersed at point $p$.** If $F$ is immersed little by little, then $F:M\rightarrow N$ is said to be immersed; - If ${F_\ast }_p$ is surjective, that is, $r({F_\ast }_p)=n,$, then $F$ is said to be **submerged at point $p$.** If $F$ is submerged little by little, then $F:M\rightarrow N$ is said to be submerged. Recall the inverse function theorem: If the open set $U,V\subset \mathbb{R}^m,$ $F:U\rightarrow V$ is a smooth mapping, $p\in U,$ $q=F(p)\in V.$ If $DF(p)$ is not degenerate, Then $\,\exists\,$ points the small neighborhood $U_1,$ of $p$,$ $q$ points the small neighborhood $V_1,$ Let $F|_{U_1}:U_1\rightarrow V_1$ be $C^\infty$ homeomorphism. Then on the manifold, Let $U\subset M^m,V\subset N^m,$ Changing the non-degenerate condition of $DF(p)$ to ${F_\ast }_p$ is a linear isomorphism, the inverse function theorem can be generalized to manifolds.
