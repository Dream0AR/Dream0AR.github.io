《现代PDE基础》笔记(1)-广义函数 "Basics of Modern PDE" Notes (1) - Generalized Function

Basic concepts -------- ### Multiple indicators $\alpha\in \mathbb{N}^n,$ $|\alpha|=\sum \alpha_i,$ $\alpha!=\prod \alpha_i !.$ as superscript, $x^\alpha=\prod x_i^{\alpha_i}$ $\partial^\alpha=\frac{\partial^{|\alpha|} }{\partial x_1^{\alpha_1}\cdots\partial x_n^{\alpha_n} },$ $f^{(\alpha)}(x)=\partial^\alpha f(x).$ The Taylor expansion of $f(x)$ is $\sum_\alpha \frac{f^{(\alpha)}(0)}{\alpha!}x^\alpha.$ $\partial^\alpha(fg)=\sum_{\beta+\gamma=\alpha}\binom{\alpha}{\beta \:\gamma}\partial^\beta f\partial^\gamma g.$ When $f,g$ satisfies appropriate conditions, an interesting proof is to consider the Fourier transform, Use binomial expansion to first prove that $\xi^\alpha (\widehat{f}\ast \widehat{g})=\sum_{\beta+\gamma=\alpha}\binom{\alpha}{\beta \:\gamma}(\xi^\beta \widehat{f})\ast (\xi^\gamma \widehat{g}),$ Then do the inverse Fourier transformation. ### Basic space Take the smooth function space $\mathscr{E}(\mathbb{R}^n)=C^\infty(\mathbb{R}^n),$ The topology is defined as, If the sequence $\{\varphi_v\}\in C^\infty(\mathbb{R}^n)$ satisfies $\,\forall\,K\Subset \mathbb{R}^n, \alpha \in \mathbb{N}^n,$ $\sup_{x\in K}|\partial^\alpha \varphi_v|\rightarrow 0,$ Then it is called $\varphi_v\rightarrow 0(C^\infty(\mathbb{R}^n)).$ Such a space is a topological linear space, which can be regarded as having multiple (half) modules. Elements tending to zero require that all (can be listed as multiple) modules tend to zero. Since it is difficult to find a unified module, Therefore it is different from Banach space. Take the compact supported smooth function space $\mathscr{D}(\mathbb{R}^n)=C_c^\infty(\mathbb{R}^n),$ The topology is defined as, If the sequence $\{\varphi_v\}\in C_c^\infty(\mathbb{R}^n)$ supports the set $K$, And $\,\forall\,\alpha\in \mathbb{N}^n,$ $\sup_{x\in K}|\partial^\alpha \varphi_v|\rightarrow 0,$ Then it is called $\varphi_v\rightarrow 0(C_c^\infty(\mathbb{R}^n)).$ Take the speed drop function space $\mathscr{S}(\mathbb{R}^n),$ To satisfy $\lim\limits_{|x|\rightarrow \infty}x^\alpha\partial^p\varphi(x)=0,$ The whole set of smooth functions of $\,\forall\,\alpha,p\in \mathbb{N}^n$. The topology is defined as, If the sequence $\{\varphi_v\}\in \mathscr{S}(\mathbb{R}^n)$ satisfies $\,\forall\,\alpha,p\in \mathbb{N}^n,$ $\sup_{x\in \mathbb{R}^n}|x^\alpha\partial^p \varphi_v(x)|\rightarrow 0,$ Then it is called $\varphi_v\rightarrow 0(\mathscr{S}(\mathbb{R}^n)).$ The condition of the rapid descent function can also be equivalently changed to bounded, or $x^\alpha$ can be replaced by $(1+|x|^2)^k,$ In order to facilitate processing. The topology of the rapid descent function space is also similar. Like the first two spaces, The space of rapid descending functions is also closed with respect to convolutions. Take $\varphi(x)=\begin{cases} e^{\frac{1}{|x|^2-1} },&|x|<1\\ 0,&|x|\ge 1. \end{cases},$ $\alpha(x)=\frac{1}{\int_{\mathbb{R}^n} \varphi dx}\varphi(x).$ Let $\beta_R=1_{B_R}\ast \alpha,$ Then $\operatorname{supp}\beta_R\subset B_{R+1},$ And $\beta_R|_{B_{R-1} }\equiv 1.$ Thus $\,\forall\,\varphi\in C^\infty(\mathbb{R}^n),$ Take $\varphi_\nu=\beta_\nu\varphi\in C_c^\infty(\mathbb{R}^n),$ Satisfies $\varphi_\nu\rightarrow \varphi(C^\infty(\mathbb{R}^n)).$ Therefore $C_c^\infty(\mathbb{R}^n)$ is dense in $C^\infty(\mathbb{R}^n)$. Similarly, It is also dense in $\mathscr{S}(\mathbb{R}^n)$. For $\mathscr{D}(\mathbb{R}^n)\subset \mathscr{S}(\mathbb{R}^n)\subset \mathscr{E}(\mathbb{R}^n),$ The front space is denser than the back space, and the front topology is stronger than the back topology. ### Regularization For the function $u(x),$ on $\Omega$, it is called **locally integrable**, If it is Lebesgue integrable on any compact set $K\Subset \Omega$. Take $\alpha_\varepsilon=\frac{1}{\varepsilon^n}\alpha(\frac{x}{\varepsilon})\in C_c^\infty(\mathbb{R}^n),$ Let $u_\varepsilon=u\ast \alpha_\varepsilon.$ If $u$ is locally integrable, then $u_\varepsilon$ is defined by, satisfying the following theorem: **Theorem 1.1**. *If $u\in L_{loc}^1(\mathbb{R}^n),$ then $u_\varepsilon\in C^\infty(\mathbb{R}^n). $ When $\varepsilon\rightarrow 0$, if $u\in C^0(\mathbb{R}^n),$ then $u_\varepsilon\rightarrow u(C^0(\mathbb{R}^n)); $ If $u\in L^p(\mathbb{R}^n),$ then $u_\varepsilon\rightarrow u(L^p(\mathbb{R}^n)).$* The first two properties are easy to prove. For the case of $u\in L^p(\mathbb{R}^n)$, using Lusin’s theorem, Just find $v\in C_c(\mathbb{R}^n)$ so that $\parallel u-v\parallel_{L^p}$ is sufficiently small. The following lemma is used in the process: **Lemma 1.2** (Minkowski integral inequality). *$\parallel\parallel f(x,y)\parallel_{L_x^1}\parallel_{L_y^p}\le \parallel\parallel f(x,y)\parallel_{L_y^p}\parallel_{L_x^1}.$* **Certificate:** Just prove (possibly restricted to a subspace) that the linear operator $\mathrm{id}:L_x^1L_y^p\rightarrow L_y^pL_x^1$ is bounded, And $\parallel\mathrm{id}\parallel\le 1.$ is based on functional analysis knowledge, The linear operator $A:X\rightarrow Y$ between normed linear spaces is bounded if and only if $A^\ast :Y^\ast \rightarrow X^\ast $ is bounded, And there is $\parallel A\parallel=\parallel A^\ast \parallel.$ It is a classic proposition to push left to right, To push the right to the left, just use $A^{\ast \ast }$, which is the extension of $A$ on $X^{\ast \ast }$. Therefore consider the linear operator $\mathrm{id}^\ast :L_y^qL_x^\infty\rightarrow L_x^\infty L_y^q,$ Instructions $\parallel\mathrm{id}^\ast \parallel\le 1$ is enough, That is $\operatorname{ess}\operatorname{sup}_x\parallel f(x,y)\parallel_{L_y^q}\le \parallel\operatorname{ess}\operatorname{sup}_x|f(x, y)|\parallel_{L_y^q},$ However this is obvious. If $\parallel\parallel f(x,y)\parallel_{L_x^1}\parallel_{L_y^p}=\infty,$ Consider using $g_n=(|f|\wedge n)\cdot 1_{B_n}$ to approximate, Just use Levi's monotonic convergence lemma to illustrate. **Corollary 1.3**. *$\parallel f\ast g\parallel_{L^p}\le \parallel f\parallel_{L^p}\parallel g\parallel_{L^1}.$* **Certificate:** $\parallel f\ast g\parallel_{L^p} \le \parallel\parallel f(x-y)g(y)\parallel_{L^1_y}\parallel_{L^p_x}\le \parallel\parallel f(x-y)g(y)\parallel_{L^p_x}\parallel_{L^1_y}=\parallel f\parallel_{L^p}\parallel g\parallel_{L^1}.$ From this inference, $\parallel u_\varepsilon-v_\varepsilon\parallel\le \parallel u-v\parallel$ is also sufficiently small, And $\parallel v-v_\varepsilon\parallel$ can also be sufficiently small by taking advantage of existing properties. The theorem is proved. Call the linear operator $J_\varepsilon:L_{loc}^1(\mathbb{R}^n)\rightarrow C^\infty(\mathbb{R}^n),$ $u\mapsto u_\varepsilon$ is the **polishing operator**, The process of obtaining $u_\varepsilon$ is called **regularization**. Theorem shows that $C^\infty(\mathbb{R}^n)$ is *dense* in $C^0(\mathbb{R}^n), L^p(\mathbb{R}^n)$, Therefore $C_c^\infty(\mathbb{R}^n), \mathscr{S}(\mathbb{R}^n)$ are also dense among them. Some simple corollaries are, $J_\varepsilon\in \mathfrak{B}(L^p(\mathbb{R}^n)\rightarrow L^p(\mathbb{R}^n));$ When $u\in \mathscr{D}/\mathscr{S}/\mathscr{E}(\mathbb{R}^n)$, $u_\varepsilon\rightarrow u(\mathscr{D}/\mathscr{S}/\mathscr{E}(\mathbb{R}^n)).$ A basic application of the polishing operator is for the open set $\Omega,$ $\,\forall\,K\Subset \Omega,$ $\,\exists\,\varphi\in C_c^\infty(\mathbb{R}^n),$ $\operatorname{supp}\varphi\subset \Omega,$ $\varphi \in [0,1],$ And $\varphi|_K\equiv 1.$ takes $\varepsilon=d(K,\Omega^c)>0,$ Just take $J_{\frac{\varepsilon}{4} } (1_{d(x,K)\le \frac{\varepsilon}{2} })$. generalized function -------- ### Definition The *linear continuous functional* on $\mathscr{D}/\mathscr{S}/\mathscr{E}(\mathbb{R}^n)$ is called the generalized function of $\mathscr{D}'/\mathscr{S}'/\mathscr{E}'(\mathbb{R}^n)$. We have the relationship $\mathscr{D}'\supset \mathscr{S}'\supset \mathscr{E}',$ This includes viewing via embedding. For example, $\mathrm{id}:\mathscr{S}'\rightarrow \mathscr{D}'$ is not only meaningful, And it's a solo shot. It makes sense because in $\mathscr{D}\subset \mathscr{S}\subset \mathscr{E}$, The former is topologically stronger than the latter; injectivity through the front space is guaranteed to be dense in the back space. Similarly, generalized functions $\mathscr{D}',\mathscr{E}'$ can be defined on the open set $\Omega$, But $\mathscr{S}'$ generalized functions are only discussed on $\mathbb{R}^n$. Easy to explain$L_{loc}^1\subset \mathscr{D}',$ And the Dirac function $\delta\in \mathscr{E}'.$ We know that on normed linear spaces, linear functionals are bounded $\Leftrightarrow$ continuous, But in topological linear space, there is no unified module, so there is no concept of "bounded". However, similar propositions still hold true and can be controlled by "some modules". **Theorem 1.4**. *If $T\in \mathscr{D}'(\Omega),$ then $\,\forall\,K\Subset \Omega,$ $\,\exists\,C(K)>0,$ $m(K)\in \mathbb{N}, $ makes $$|\left<{}T,\varphi\right>|\le C(K)\sup_{x\in \Omega,|\alpha|\le m}|\partial^\alpha \varphi(x)|, \,\forall\,\varphi\in C_c^\infty(K)\subset C_c^\infty(\Omega).$$* *On the other hand, if $T$ is a linear functional that satisfies the above conditions, then it is continuous, $T\in \mathscr{D}'(\Omega).$* **Certificate:** Definition $|\varphi|_\nu=\sup\limits_{x\in \Omega,|\alpha|\le \nu} |\partial^\alpha \varphi(x)|,$ Satisfies $|\varphi|_\nu\le |\varphi|_\mu,$ $\,\forall\,\nu\le \mu.$ If $T\in \mathscr{D}'(\Omega)$ does not satisfy propositional properties, Then $\,\exists\,K\Subset \Omega,$ $\{\varphi_\nu\}\in C_c^\infty(K),$ Such that $|\left<{}T,\varphi_\nu \right>|>\nu|\varphi_\nu|_\nu.$ Multiply $\varphi_\nu$ so that $|\left<{}T,\varphi_\nu\right>|=1,$ Then $|\varphi_\nu|_\nu<\frac{1}{\nu}.$ It is easy to see that $\varphi_\nu\xrightarrow{\mathscr{D} } 0,$ But $|\left<{}T,\varphi_\nu\right>|\equiv 1,$ $\left<{}T,\varphi_\nu\right>\not\rightarrow 0,$ Contradiction. On the contrary, if $T$ is a linear functional that satisfies the conditions, $\,\forall\,\varphi_\nu\xrightarrow{\mathscr{D} } 0,$ $\,\exists\,K$ makes $\{\varphi_\nu\}\in C_c^\infty(K).$ According to the conditions, there are corresponding $C(K),m(K),$ Such that $|\left<{}T,\varphi_\nu\right>|\le C|\varphi_\nu|_m\rightarrow 0.$ Therefore $\left<{}T,\varphi_\nu\right>\rightarrow 0,$ $T\in \mathscr{D}'(\Omega).$ **Theorem 1.5**. *If $T\in \mathscr{E}'(\Omega),$ then $\,\exists\,K\Subset \Omega,$ $C>0,$ $m\in \mathbb{N},$ such that $$|\left<{}T,\varphi\right>|\le C\sup_{x\in K,|\alpha|\le m}|\partial^\alpha \varphi(x)|, \,\forall\,\varphi\in C^\infty(\Omega).$$* *On the contrary, if $T$ is a linear functional satisfying the above conditions, Then it is continuous, $T\in \mathscr{E}'(\Omega).$* **Proof:** Take the compact set $K_\nu=B_\nu\cap \{x:d(x,\Omega^c)\ge \frac{1}{\nu}\},$ Then $K_\nu$ increases and $\bigcup K_\nu=\Omega.$ $\,\forall\,K\Subset \Omega,$ $\,\exists\,N>0,$ $\,\forall\,\nu>N,$ $K\subset K_\nu.$ Definition $|\varphi|_\nu=\sup\limits_{x\in K_\nu,|\alpha|\le \nu} |\partial^\alpha \varphi(x)|,$ Satisfies $|\varphi|_\nu\le |\varphi|_\mu,$ $\,\forall\,\nu\le \mu.$ The same theorem as above can prove that $T\in \mathscr{E}'(\Omega)$ satisfies propositional properties. On the contrary, if $T$ is a linear functional that satisfies the conditions, $\,\forall\,\varphi_\nu\xrightarrow{\mathscr{E} } 0,$ Take $K,$ which makes the property true Then $\sup_{x\in K}|\partial^\alpha\varphi(x)|\rightarrow 0,$ $\,\forall\,\alpha\in \mathbb{N}^n.$ Therefore $|\left<{}T,\varphi_\nu\right>|\le C\sup\limits_{x\in K,|\alpha|\le m}|\partial^\alpha\varphi_\nu(x)|\rightarrow 0.$ Therefore $\left<{}T,\varphi_\nu\right>\rightarrow 0,$ $T\in \mathscr{E}'(\Omega).$ It can be seen that $\mathscr{D}',\mathscr{E}'$ satisfy a certain duality relationship: In $\mathscr{D}$, the function has a compact support set, and convergence requires a common compact set, Therefore, the continuity condition of the linear functional on it is appropriately relaxed, Compact support functions on different compact sets only need to satisfy a certain boundedness; and in $\mathscr{E}$, The function has no compact support, and convergence requires that any compact set must meet certain conditions. This causes the continuity condition of the linear functional on it to become strict, and the boundedness needs to be controlled by a compact set. And it is required that all smooth functions consistently satisfy boundedness. This is $\mathscr{D}\subset \mathscr{E}\rightarrow \mathscr{D}'\supset \mathscr{E}'.$ This dual relationship will be stronger in the next section. ### Support For a generalized function, the meaning of its value at a specific point is not clear, but we can talk about its value on an open set. For $T\in \mathscr{D}'(\Omega),$ give an open set $\Omega'\subset \Omega,$ If $\,\forall\,\varphi\in C_c^\infty(\Omega'),$ $\left<{}T,\varphi\right>=0,$ then $T$ is said to take zero value on $\Omega'$. It is further said that $T_1, T_2$ have the same value on $\Omega'$, if $T_1-T_2$ takes zero value on $\Omega'$. Therefore, if a generalized function and a normal function (induced linear continuous functional) have the same value on an open set, Then it can be said that the generalized function is equal to this normal function on the open set. If the normal function takes zero at every point, the whole is zero. Similarly, if the generalized function takes zero at a small neighborhood, Then the whole is zero. For proof, just use the *Unit Decomposition Theorem*. For $\varphi\in C_c^\infty(\Omega),$ Take the unit decomposition $\{\varphi_i\}$ which belongs to the open cover $\{O_i\}$ consisting of a finite number of small neighbors covering $\operatorname{supp}\varphi$. Then $\varphi_i \varphi\in C_c^\infty(O_i),$ And on the entire $\Omega$$\sum_i \varphi_i\varphi=\varphi.$ Then the generalized function acting on $\varphi$ can be decomposed into $\{O_i\}$, Then linear combination can be used to take the value. The sum of zero values is still zero, so the generalized function takes zero value in the whole space. Due to this property, the generalized function still takes zero value on the union of all open sets that takes zero value. The sum of all open sets is still an open set, so we can define the largest open set in which the generalized function takes zero value. Then the complement of the maximum open set is called the **support** of the generalized function, Denoted as $\operatorname{supp}T.$ for the continuous function $f(x),$ It is easy to see that its support as a generalized function is the same as the support originally defined. Therefore, the definition of generalized function supports is an extension of the definition of continuous function supports. **Theorem 1.6**. *Any $T\in \mathscr{E}'(\Omega)$ has compact support; conversely, any compactly supported set $T\in \mathscr{D}'(\Omega),$ $T$ is also in $\mathscr{E}'(\Omega)$.* **Proof:** From the theorem of the previous section, $\,\forall\,T\in \mathscr{E}'(\Omega),$ $\,\exists\,K\Subset \Omega,$ $C>0,$ $m\in \mathbb{N},$ such that $$|\left<{}T,\varphi\right>|\le C\sup\limits_{x\in K,|\alpha|\le m}|\partial^\alpha\varphi(x)|,\,\forall\,\varphi\in C^\infty(\Omega),$$ We show that $K$ contains the support of $T$, so that the support is compact. This is easy, Because as long as $\operatorname{supp}\varphi\subset \Omega\setminus K,$ The right-hand side of the inequality is zero, thus forcing $T$ to take zero value on $\Omega\setminus K$, and the support is within $K$. On the contrary, if $T\in \mathscr{D}'(\Omega)$, We hope to extend its domain from $\mathscr{D}(\Omega)$ to $\mathscr{E}(\Omega),$ To this end, we need to find a way to transform the smooth function into a compact support without changing the value of the functional. Naturally, we can think of using its support. Note $\operatorname{supp}T=K\Subset \Omega$, Then take $K\Subset \Omega_1\Subset \Omega,$ Make $\zeta\in C_c^\infty(\overline{\Omega}_1),$ $\zeta\in[0,1]$ and $\zeta|_{\overline{O}_\delta(K)}\equiv 1.$ For $\varphi\in C^\infty(\Omega),$ Definition$\left<{}T,\varphi\right>=\left<{}T,\zeta\varphi\right>,$ $\zeta\varphi\in C_c^\infty(\overline{\Omega}_1).$ needs to verify the rationality of the definition: If there is $\eta\in C_c^\infty(\overline{\Omega}_2),$ $\eta\in [0,1]$ and $\eta|_{\overline{O}_{\varepsilon}(K)}\equiv 1,$ Then $\zeta-\eta\in C_c^\infty(\Omega \setminus K),$ The support lies outside the generalized function support, Thus $\left<{}T,\zeta\varphi\right>-\left<{}T,\eta\varphi\right>=\left<{}T,(\zeta-\eta)\varphi\right>=0.$ In this way, the functional can act on $\varphi$, and according to the theorem about $\mathscr{D}'$ in the previous section, $$|\left<{}T,\varphi\right>|\le C|\zeta\varphi|_m\le C'\sup_{x\in \Omega_1,|\alpha|\le m}|\partial^\alpha\varphi|,$$ Then from the theorem about $\mathscr{E}'$, $T$ is also continuous after being transformed into a linear functional on $\mathscr{E}$, That is $T\in \mathscr{E}'(\Omega).$ It can be seen that $\mathscr{D}'_c=\mathscr{E}',$ This is a duality with $\mathscr{D}=\mathscr{E}_c$, which is very pleasing to the eye. It can be seen as making $\left<{}T,\varphi\right>$ reasonable. When the conditions on one side are weak, The conditions on the other side must be stronger. The second half of the proof says, In order to allow $T\in \mathscr{D}'_c$ to act on $\varphi$ in $\mathscr{E}$, Just consider the effect on the $\varphi|_{\operatorname{supp}T}$ part, Because the remaining parts fall outside the support set. As far as specific operations are concerned, they cannot be directly restricted. It needs to be transformed into a compactly supported set function using the method in the proof. In fact, for the auxiliary function $\zeta,$ (used to transform $\varphi$) The requirement can be replaced by $\zeta|_K=1.$ This is because $\delta$ of $\overline{O}_\delta(K)$ can be arbitrarily small, You can get $\zeta_\delta\xrightarrow{\mathscr{D} }\zeta,$ Just use the continuity of the linear functional ($T\in \mathscr{D}'$).
