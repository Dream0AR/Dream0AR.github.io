Hausdorff measure ------------- ### Basic definition This section assumes that $(X,d)$ is a metric space. Remember $\omega_m=\frac{\pi^{m/2} }{\Gamma(\frac{m}{2}+1)},$ Among them $\Gamma(q)=\int_0^\infty t^{q-1}e^{-t}dt,$ $q>0.$ When $m\in \mathbb{Z}_+$, $\omega_m$ represents the volume of the $m$-dimensional unit ball $B_1^m(0)$. For any $m\ge 0,$, define the $m$-dimensional Hausdorff (external) measure as $$\mathcal{H}^m(A)=\lim\limits_{\delta\rightarrow 0+}\mathcal{H}_\delta^m(A),\quad A\subset X,$$ Among them, $\mathcal{H}_\delta^m$ is called the $\delta$ approximation of $\mathcal{H}^m$, $\mathcal{H}_\delta^m(\varnothing):=0;$ $\,\forall\,$not empty$A\subset X,$ $\mathcal{H}_\delta^m(A):=\omega_m\inf\sum_{j}\left(\frac{\operatorname{diam}C_j}{2}\right)^m,$ The lower bound satisfies $C_1,\cdots\subset X,$ $\operatorname{diam}C_j<\delta,$ Take the set column of $A\subset \bigcup_j C_j$. If no such set column is found, It is regarded as $\inf \varnothing=+\infty.$ It is easy to verify that $\mathcal{H}_\delta^m$ and $\mathcal{H}^m$ are both external measures. Since $H_\delta^m$ is reduced with respect to $\delta$, Therefore, the limit at $\delta\rightarrow 0+$ always exists (possibly $+\infty$), Therefore, we can remember $\mathcal{H}^m(A)=\sup_{\delta>0}\mathcal{H}_\delta^m(A).$ It is easy to verify that $\mathcal{H}^m$ and $\mathcal{H}_\delta^m$ are both external measures. Note that $\mathcal{H}^0$ is actually a counting measure. **Note 1.1**. *Since $\operatorname{diam}C=\operatorname{diam}\overline{C},$ can additionally require that the set selected in $\mathcal{H}_\delta^m$ be a closed set. Since a closed set has a small open neighborhood, an open set can also be selected. For a completely bounded set $A,$ $\mathcal{H}_\delta^m(A)<\infty,$ $\,\forall\,m\ge0,$ $\delta>0.$* It is easy to see that $\mathcal{H}^m$ satisfies the Caratheodory criterion, Therefore $\mathcal{H}^m$ is a Borel measure. In particular, from the previous notation, It is easy to show that it is still a Borel regular measure. However, it should be noted that, $\mathcal{H}_\delta^m$ is not necessarily a Borel measure, for example, on $\mathbb{R}^2$, For $\mathcal{H}_1^1,$ take $S_\frac{1}{2}=I\times \{0,\frac{1}{2}\},$ $I=[0,1].$ Then $\mathcal{H}_1^1(S_\frac{1}{2})<2,$ But for the Borel set $\mathbb{H}=\{y>0\},$ $\mathcal{H}_1^1(S_\frac{1}{2}\cap \mathbb{H})=\mathcal{H}_1^1(S_\frac{1}{2}\setminus \mathbb{H})=1,$ Therefore $\mathbb{H}$ does not satisfy the Caratheodory condition and is not a $\mathcal{H}_1^1$-measurable set. ### Geometric meaning In fact, for the integer $m\ge 1,$ $\mathcal{H}^m$ is exactly the volume measure of the $m$-dimensional $C^1$ submanifold in $\mathbb{R}^{n}$, $n\ge m.$ Let us first explain that $\mathcal{H}^n,\mathcal{L}^n$ are consistent on $\mathbb{R}^n$. First recall the definition of $\mathcal{L}^n$. Define $\mathcal{K}$ to be the set of all $n$-dimensional open intervals $I=(a_1,b_1)\times\cdots\times(a_n,b_n)$. Define the volume of the open interval $|I|=(b_1-a_1)\cdots(b_n-a_n).$ Next define $\mathcal{L}^n(A)=\inf\sum_j |I_j|,$ The lower bound satisfies $\{I_j\}\in \mathcal{K},$ Take it from the set column of $A\subset\bigcup_jI_j$. It is easy to see that $\mathcal{L}^n$ is characterized by an external measure with the following characteristics: $$\mu^n(I)=|I|,\,\forall\,I\in \mathcal{K},\quad \mu^n(A)=\inf_{\text{开}U\supset A}\mu^n(U),\,\forall\,A\subset \mathbb{R}^n.$$ This is because according to the Caratheodory criterion, $\mu^n$ is a Borel (regular) measure, Therefore, the sets generated by $\mathcal{K}$ under columnable union/intersection/complement operations are all measurable sets. $\mathcal{K}$ is closed under finite union, so it is not difficult to prove that for finite union, There are $\mu^n(\bigcup_jI_j)=\mathcal{L}^n(\bigcup_jI_j),$ Furthermore, pairs of monotonicity can be combined into pairs. And $\mathcal{K}$ is the topological basis, Generate all open sets under the union operation, Therefore $\mu^n(U)=\mathcal{L}^n(U)$ holds for all open sets $U$, Then by definition, $\mu^n=\mathcal{L}^n.$ Next we prove that $\mathcal{L}^n(A)=\mathcal{H}^n(A),$ In fact, it can be explained that $\mathcal{L}^n(A)=\mathcal{H}_\delta^n(A),$ For this reason, first explain: **Lemma 1.2**. *$\mathcal{H}_\delta^n(A)\le \mathcal{L}^n(A),$ $\,\forall\,\delta>0.$* **Proof:** By Vitali/Besicovitch covering lemma (introduced in the next section), for any open set $U,$ A family of unintersected closed spheres can be found $\{B_j\},$ $\operatorname{diam}B_j<\delta,$ $B_j\subset U,$ $\mathcal{L}^n(U\setminus \bigcup_j B_j)=0.$ That is, the closed sphere family covers $U.$ in the sense of $\mathcal{L}^n$ measure. It is easy to see from the definition that $\mathcal{L}^n(A)=0\Leftrightarrow \mathcal{H}_\delta^n(A)=0,$ Therefore, there is also $\mathcal{H}_\delta^n(U\setminus \bigcup_j B_j)=0.$ Let $U$ be $I_k\in \mathcal{K}.$ then $$\begin{aligned} \mathcal{H}_\delta^n(I_k)&=\mathcal{H}_\delta^n(\cup_jB_j)\le\sum_j \omega_n\left(\frac{\operatorname{diam}B_j}{2}\right)^n\\ &=\sum_j\mathcal{L}^n(B_j)=\mathcal{L}^n(\cup_j B_j)=\mathcal{L}^n(I_k)=|I_k|. \end{aligned}$$ Then $\,\forall\,A\subset \bigcup_k I_k,$ $$\mathcal{H}_\delta^n(A)\le\mathcal{H}_\delta^n(\cup_k I_k)\le \sum_k\mathcal{H}_\delta^n(I_k)\le \sum_k |I_k|.$$ Take the exact bound for all such $\{I_k\}$, That means $\mathcal{H}_\delta^n(A)\le \mathcal{L}^n(A).$ In order to explain the reverse inequality, we first need the following theorem: **Theorem 1.3** (equal diameter inequality). *$\mathcal{L}^n(A)\le \omega_n\left(\frac{\operatorname{diam}A}{2}\right)^n.$* **Proof:** Just prove that $A$ is a compact set, Because $\operatorname{diam}A=\infty$ is trivial (bounded), And $A\subset \overline{A},$ $\operatorname{diam}{\overline{A} }=\operatorname{diam}{A}$(closed). For the compact set $A,$ we do *Steiner symmetrization*: in the $x^j$ direction, For all coordinate points $\xi,$ whose $j$ component is $0$ Intercept the part where $A$ intersects $x^j$ line $\ell_j(\xi)$ starting from $\xi$ point, Reset to a line segment of the same length with $\xi$ as the midpoint and falling on the $x^j$ line, as shown in the figure below. First, it is explained that the symmetrized set is compact, which will be used later when the diameter is reduced. Just say that it is closed. Let $A$ intercept the length in $x^j$ direction at $\xi$ point as $2f(\xi),$ Then $\,\forall\,\xi_i\rightarrow \xi,$ $t_i\rightarrow t,$ $|t_i|\le f(\xi_i),$ Need to explain $|t|\le f(\xi).$ Just need to explain that $f$ is upper semi-continuous, In this way, we have $f(\xi)\ge \varlimsup_i f(\xi_i)\ge \varlimsup_i |t_i|=|t|.$ Let $\pi:\mathbb{R}^n\rightarrow \mathbb{R}$ be the projection in the $x^j$ direction, Then $f(\xi)=\mathcal{L}^1(\pi(A\cap \ell_j(\xi))).$ $\,\forall\,\varepsilon>0,$ You can take the open interval $U\supset\pi(A\cap \ell_j(\xi)),$ Such that $\mathcal{L}^1(U)\le f(\xi)+\varepsilon.$ Take the open set $\pi^{-1}(U)\supset A\cap \ell_j(\xi),$ We show that for $\eta,$ that is sufficiently close to $\xi$ There is $A\cap\ell_j(\eta)\subset \pi^{-1}(U).$ otherwise there is $\xi_i\rightarrow \xi,$ So that there is always a point $x_i=\xi_i+s_i e_j,$ in $A\cap \ell_j(\xi_i)$ that is not in $\pi^{-1}(U)$ $s_i\in \mathbb{R}.$ Since $A$ is bounded, the bounded point sequence $\{s_i=\pi(x_i)\}$ has a convergent subsequence, Let's assume it converges itself, then $x_i=\xi_i+s_i e_j\rightarrow \xi+s e_j=:x.$ Since $U^c$ is closed, $\pi(x)\notin U,$ But $x\in A\cap \ell_j(\xi)\subset \pi^{-1}(U),$ is contradictory. This means $\,\exists\,\delta>0,$ $\,\forall\,\eta\in O_\delta(\xi),$ $f(\eta)\le f(\xi)+\varepsilon,$ means $f$ is upper semi-continuous. According to Fubini's theorem, the measure of $\mathcal{L}^n$ remains unchanged after symmetry, The diameter after symmetrization is smaller than the original, so just consider the case after symmetry to prove it. The diameter decreases because assuming that after symmetry $a, b$ is $|b-a|$, two points of the diameter length are obtained, Then their symmetry points $\widetilde{a} and \widetilde{b}$ about $x^j=0$ are also two points where $|\widetilde{b}-\widetilde{a}|$ takes the diameter length. If the distance between $a,b$ in the original set is less than $|b-a|,$ Then the distance between $\widetilde{a},\widetilde{b}$ in the original set will definitely be enlarged. This can be simply explained using the Pythagorean theorem. It is easy to prove that after performing Steiner symmetrization in the $x^j$ direction on a set that is already symmetric about $x^i=0$, It is still symmetric about $x^i=0$. Therefore, after doing Steiner symmetrization of $A$ in all $x^j$ directions, It is symmetrical in all $x^j$ directions, especially centrally symmetrical. Denote it as $\widetilde{A},$ Then it must be included in the sphere with the origin as the center, $\operatorname{diam}\widetilde{A}$ is inside a closed sphere with diameter. This proposition is proved. **Theorem 1.4**. *$\mathcal{L}^n(A)=\mathcal{H}^n(A)=\mathcal{H}^n_\delta(A),$ $\,\forall\,A\subset \mathbb{R}^n, \delta>0.$* **Proof:** From the previous lemma, Just explain $\mathcal{L}^n(A)\le \mathcal{H}_\delta^n(A).$ And this is obtained immediately from the above inequality, which is the same as the lemma proof method. That is $\,\forall\,A\subset C_j,$ $$\mathcal{L}^n(A)\le \mathcal{L}^n(\cup_j C_j)\le \sum_j\mathcal{L}^n(C_j)\le \sum_j\omega_n\left(\frac{\operatorname{diam}C_j}{2}\right)^n.$$ Then take the exact bound for all such $\{C_j\}$, That is, $\mathcal{L}^n(A)\le \mathcal{H}_\delta^n(A).$ The article was last updated on 2021-10-25 10:58:21
