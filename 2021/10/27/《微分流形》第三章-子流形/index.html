《微分流形》第三章-子流形 "Differential Manifolds" Chapter 3 - Submanifolds

submanifold ------ Let $F:M^m\hookrightarrow N^n$ be a submanifold. If $\,\forall\,p\in M,$ There exists a coordinate system $(V,\psi,y^\alpha),$ in $N$ containing $q=F(p)$ If $F(M)\cap V$ is a slice in $V$, then $(M,F)$ is said to be a **regular submanifold** in $N$. In addition, $F(M)$ is a subset of $N$, and the subspace topology can be induced from $N$, You can also move the topology on $M$ to $F(M)$ through $F$. If the two induced topologies are consistent, Then $(M,F)$ is called **embedded submanifold**. **Theorem 1.1**. *Suppose $F:M\rightarrow N$ is a submanifold, then $(M,F)$ is a regular submanifold if and only if it is an embedded submanifold.* For proof, please refer to "Preliminary Riemannian Geometry" by Bai and Shen. **Theorem 1.2**. *Suppose $F:M\rightarrow N$ is a submanifold. If $M$ is compact, then $(M,F)$ must be an embedded submanifold.* **Proof:** Assign $F(M)$ as the topology $\mathcal{T},$ induced by the subset of $N$ Just explain that $F:M\rightarrow F(M)$ is a homeomorphism. First, explain that $F$ is continuous. For any open set $U\subset F(M),$ there exists an open set $\widetilde{U}\subset N,$ Such that $U=\widetilde{U}\cap F(M).$ Then $F^{-1}(U)=F^{-1}(\widetilde{U})$ is an open set in $M$. Next, $F$ is a closed map. The continuous mapping from compact space to $T_2$ space is a closed mapping, which is proved. **Theorem 1.3**. *Suppose $F:M^m\rightarrow N^n$ is a smooth mapping. Take $q\in N,$ and define $P:=F^{-1}(q).$ if $\,\forall\,p\in P,$ $r({F_{\ast } }_p)=n,$ Then $P$ has a unique $C^\infty$-manifold structure such that $(P,i)$ is a regular submanifold of $M$, $\dim P=m-n.$* **Proof:** According to the rank theorem, a suitable box coordinate system can be obtained so that $\widehat{F}$ is a projection. Therefore $\widehat{F}^{-1}(0)=\{(0,\cdots,0,x^{n+1},\cdots,x^m)||x^\gamma|<\delta\},$ That is, $\widehat{F}^{-1}(0)=F^{-1}(q)\cap U$ is an $n$-dimensional slice in $U$. Assign $P$ subspace topology, take coordinate atlas $\{(P\cap U,\pi\circ\varphi)\},$ It is easy to see that $P$ becomes an $m-n$ dimensional topological manifold. At the same time, it is easy to see that the atlas satisfies $C^\infty$ compatibility, Therefore $P$ has a $C^\infty$-manifold structure. Obviously injective $i\in C^\infty(P,M)$ with rank $m-n,$ Therefore it is a submanifold. From the previous explanation, it is also a slice locally, so $(P,i)$ is a regular submanifold. **Corollary 1.4**. *If the surjection $F:M\rightarrow N$ is submerged, then $\,\forall\,q\in N,$ $F^{-1}(q)$ is an $m-n$ dimensional regular submanifold in $M$.* One problem is that given $C^\infty$ manifold $M^m,$ Does $F:M\rightarrow \mathbb{R}^N,$ exist? Let $(M,F)$ be the $\mathbb{R}^N$ neutron manifold. H.Whitney pointed out, There exists $F:M^m\hookrightarrow \mathbb{R}^{2m+1}$ as a regular submanifold. Integral curve of vector field ---------------- Let $X\in \chi(M),$ $\gamma:(a,b)\rightarrow M$ be $C^\infty$-curve, If $\gamma'(t)=X_{\gamma(t)},$ $\,\forall\,t\in (a,b).$ Then $\gamma$ is said to be the **integral curve** of $X$. If $0\in(a,b),$ $p=\gamma(0)$ is called the **initial point** of $\gamma$. Given $X\in\chi(M),$ $p\in M.$ any coordinate system $(U,\varphi;x^i),$ $\{X_i\}_{i=1}^m$ is a natural basis. Then $X|_U=\sum \xi^iX_i,$ $\xi^i\in C^\infty(U).$ and $\gamma'(t)=\sum_i \frac{dx^i(t)}{dt}X_i,$ Therefore, to find the integral curve $\gamma$ is to solve the system of ordinary differential equations after given the initial value: $$\frac{dx^i}{dt}=\xi^i(\gamma(t))=\widehat{\xi}^i(x^1,\cdots,x^m),\quad i=1,\cdots,m.$$ Where $\widehat{\xi}^i=\xi^i\circ\varphi^{-1}\in C^\infty(\varphi(U)).$ According to the fundamental theorem of ordinary differential equations, we have the following proposition: **Proposition 1.5**. *Suppose $X\in\chi(M),$ then $\,\forall\,p\in M,$ $\,\exists\,\varepsilon>0,$ $\gamma:(-\varepsilon,\varepsilon)\rightarrow M,$ such that $\gamma(0)=p$ and $\gamma$ is the integral curve of $X$.* Suppose $X\in\chi(M),$ If $X_p=0,$ then $p$ is called the **singularity** of $X$. A classic proposition is, A smooth vector field on a sphere must have singular points. A typical proof is to apply the index theorem, The Euler characteristic number of the sphere is non-zero. Recall that the tangent bundle $TM$ is a $2m$ dimensional $C^\infty$ manifold, for $U\subset M,$ There is a local trivialization $\widetilde{\Phi}:TU=\pi^{-1}(U)\cong U\times \mathbb{R}^m$ which is a diffeomorphism, And $\widetilde{\Phi}|_{T_{p}M}:T_pM\rightarrow \{p\}\times \mathbb{R}^m$ is line isomorphism (fiber preserving). Then the above proposition explains, $TS^2\not\cong S^2\times \mathbb{R}^2,$ That is, the spherical tangent bundle is a non-trivial bundle. The article was last updated on 2021-10-27 21:07:04
