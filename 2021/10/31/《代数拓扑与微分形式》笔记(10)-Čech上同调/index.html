pre-layer ---- The pre-layer $\mathcal{F}$ on $X$ means, assigning an abel group $\mathcal{F}(U)$ to each open set of $X$, Give each open set a containing $V\subset U$ group homomorphism $\rho^U_V:\mathcal{F}(U)\rightarrow\mathcal{F}(V)$, is called a restriction. Meets the requirements of category theory: $\rho^U_U=\mathrm{id}$, And there is transitivity $\rho^V_W\circ\rho^U_V=\rho^U_W$. For example, a continuous function pre-layer on $X$, $C^0(U)$ is a continuous function on $U$, $\rho^U_V$ is the limit of the usual function. $\Omega^\ast $ is also a pre-layer. Especially for $0\le q\le \dim M$, $\Omega^q$ is also a pre-layer. If $\mathcal{F},\mathcal{G}$ is the upper pre-layer of $X$, For every open set $U$ there is a homomorphism $f_U:\mathcal{F}(U)\rightarrow\mathcal{G}(U)$, If $\rho^U_Vf_U=f_V\rho^U_V$, then $\{f_U\}$ is called a homomorphism on the pre-layer; If every isomorphism is an isomorphism, then $\{f_U\}$ is an isomorphism of the pre-layer, $\mathcal{F}\cong \mathcal{G}$. Looking at it in the language of category theory, The homomorphism $f$ of the two prelayers is the natural transformation on the two functors $\mathcal{F},\mathcal{G}$. Call $\mathcal{F}$ a constant pre-layer whose value is in abel group $G$, If $\mathcal{F}(U)$ is the set of local constant functions on $U$ that take values in $G$, And $\rho^U_V$ is the limit of ordinary functions. So if $U$ is connected, then $\mathcal{F}(U)\cong G$, And if $V\cap U$ is the inclusion of two connected open sets, then $\rho^U_V=\mathrm{id}_G$. It is customary to record this constant value pre-layer as $G$. If there is a fiber bundle $\pi:E\rightarrow M$, then the pre-layer $\mathcal{H}^q$ can be defined on $M$, $\mathcal{H}^q(U)=H^q(\pi^{-1}(U))$, limiting $\rho^U_V$ induced by $i^\ast $, Contains the mapping $i:\pi^{-1}(V)\rightarrow \pi^{-1}(U)$. (Supercohomology can be constructed on the prelayer $\mathcal{H}^q$.) When $U$ is shrinkable, $\pi^{-1}(U)\cong U\times F$, according to Künneth's formula, $\mathcal{H}^q(U)\cong H^q(F)$. If $V$ is the inclusion of a shrinkable open set, Then $\rho^U_V$ is isomorphism. The pre-layer $\mathcal{H}^q$ is an example of covering a local constant pre-layer, It has fundamental importance in the fibrosis spectrum sequence. Open Covered Čech Cohomology ------------------ Let $\mathcal{F}$ be the pre-layer on the topological space $X$, $\mathcal{U}=\{U_\alpha\}$ be the open cover, Define $C^0(\mathcal{U},\mathcal{F})=\prod\mathcal{F}(U_\alpha)$. Let $\omega\in C^0(\mathcal{U},\mathcal{F})$, Specify $\omega_\alpha\in \mathcal{F}(U_\alpha)$ for each $U_\alpha$. $\omega$ is called a $0$-on-chain on $\mathcal{U}$ whose value is equal to $\mathcal{F}$. Definition $C^1(\mathcal{U},\mathcal{F})=\prod\mathcal{F}(U_{\alpha\beta})$, Additionally, specify $\omega_{\alpha\beta}=-\omega_{\beta\alpha}$. Called $1$-on-chain. Similarly, we can define $p$-on-chain $\omega\in C^p(\mathcal{U},\mathcal{F})$, Specify $\omega_{\alpha_0\cdots\alpha_p}$ for any $p+1$ open sets with non-empty intersection, It is required to invert the sign after exchanging subscripts. For simplicity, let us note the restriction $\rho^U_V(\omega_U)=\omega_U|_V$, $|_V$ can also be omitted when it is clear, because the restriction is transitive. Next define the difference operator $\delta:C^p(\mathcal{U},\mathcal{F})\rightarrow C^{p+1}(\mathcal{U},\mathcal{F})$, The components of $\delta\omega$$(\delta\omega)_{\alpha_0\cdots\alpha_{p+1} }=\sum_{i=0}^{p+1}(-1)^i\omega_{\alpha_0\cdots\hat\alpha_i\cdots\alpha_{p+1} }$. By restricted transitivity, $\delta^2=0$. The cohomology $H^\ast (\mathcal{U},\mathcal{F})$ of the complex $\{C^\ast (\mathcal{U},\mathcal{F}),\delta\}$ is said to be the Čech cohomology covering $\mathcal{U}$ whose value is in the pre-layer $\mathcal{F}$. If $\mathcal{F}$ is covariant, Then we have $\partial:C_p(\mathcal{U},\mathcal{F})\rightarrow C_{p-1}(\mathcal{U},\mathcal{F})$, $(\partial \omega)_{\alpha_0\cdots\alpha_{p-1} }=\sum_{\alpha}\omega_{\alpha\alpha_0\cdots\alpha_{p-1} }$. Returning to the discussion of Čech cohomology on $\mathcal{F}$, If $\mathcal{V}$ is a subdivision of $\mathcal{U}$, That is, $\,\exists\,\phi:J\rightarrow I$ is the mapping of the indicator set, $V_\beta\subset U_{\phi\beta}$, $\,\forall\,\beta\in J$. $\phi$ is called thinning mapping. $\phi$ induced $\phi^\sharp:C^q(\mathcal{U},\mathcal{F})\rightarrow C^q(\mathcal{V},\mathcal{F})$, $(\phi^\sharp\omega)_{\beta_0\cdots\beta_q}=\omega_{\phi(\beta_0)\cdots\phi(\beta_q)}$. It is easy to verify that $\phi^\sharp$ is a chain map. If there is another thinning mapping $\psi:J\rightarrow I$, Then $\phi^\sharp\simeq\psi^\sharp$ chain homotopy. In fact, Take the homotopy operator $K:C^q(\mathcal{U},\mathcal{F})\rightarrow C^{q-1}(\mathcal{V},\mathcal{F})$, $(K\omega)_{\beta_0\cdots\beta_{q-1} }=\sum_{i=0}^{q-1}(-1)^i\omega_{\phi(\beta_0)\cdots\phi(\beta_i)\psi(\beta_i)\cdots\psi(\beta_{q-1})}$. Thus, There is an induced mapping $\phi^\sharp:H^q(\mathcal{U},\mathcal{F})\rightarrow H^q(\mathcal{V},\mathcal{F})$, And it has nothing to do with the selection of $\phi$. directed limit -------- Given a partially ordered set $(I,\le)$, if it also satisfies $\,\forall\,a,b\in I, \,\exists\,c\in I$, $a,b\le c$, then $I$ is called a directed set. Define the directed system of the group as the set class $\{G_\alpha\}$ of the group, taking the directed set as the index set, Such that $\,\forall\,a\le b$, exists group homomorphism $f^a_b:G_a\rightarrow G_b$, $f^a_a=\mathrm{id}$, $f^a_c=f^b_c\circ f^a_b$, if $a\le b\le c$. Define the equivalence relation $\sim$, $g_{a}\sim g_b$ if $\,\exists\,c$, $a,b\le c$, $f^a_c(g_a)=f^b_c(g_b)$. Define the directed limit of the directed system $\{G_a\}$ of the group as $\lim_{a\in I}G_a=(\prod_{a\in I}G_a)/\sim$, Addition is naturally defined as $[g_a]+[g_b]=[f^a_c(g_a)+f^b_c(g_b)]$, $a,b\le c$. Well-determined and directed limits become groups. Čech cohomology of topological spaces ------------------- Apply the above theory to $H^\ast (\mathcal{U},\mathcal{F})$, that is: 1. The directed set is an open covering set of $X$, $I=\{\mathcal{U},\mathcal{V},\cdots\}$ 2. The partial order is to add finer $\mathcal{U}>\mathcal{V}$ 3. Take the abel group $G_\mathcal{U}=H^\ast (\mathcal{U},\mathcal{F})$ 4. $\phi:\mathcal{V}\rightarrow \mathcal{U}$ is the thinning mapping, Restrict $\phi^\sharp:G_\mathcal{U}\rightarrow G_\mathcal{V}$ to be homomorphic 5. If $\varphi=\phi\circ\psi$, Then $\varphi^\sharp=\psi^\sharp\circ\phi^\sharp$ In this way $\{H^\ast (\mathcal{U},\mathcal{F})\}_{\mathcal{U}\in I}$ becomes the directed system of the group, Its directed limit $\lim_\mathcal{U}H^\ast (\mathcal{U},\mathcal{F})$ is called the topological space $X$ whose value is Čech cohomology of the pre-layer $\mathcal{F}$, Denoted as $H^\ast (X,\mathcal{F})$. **Proposition 1.1**. *$H^\ast (M,\mathbb{R})\cong H^\ast _{dR}(M)$.* **Proof:** For any open covering $\mathcal{U}$, We can actually get a finer good covering $\mathcal{V}$, Because it is enough to consider each point as a geodesic convex neighborhood. In particular, the manifold satisfies the $C_2$ countability axiom, Therefore it is still countable. $\,\forall\,a,b\in H^\ast (\mathcal{U},\mathcal{F})$, if $[a]\neq[b]$, Then for each such $\mathcal{V}$, $a,b$ has different restrictions on it. If $[a]=[b]$, Then there exists $\mathcal{W}$, on which $a and b$ have the same restrictions. Then by transitivity, Take the addition of $\mathcal{W}$ to cover $\mathcal{V}$, and $a, b$ are restricted to be equal on it. Therefore, we only need to examine $H^\ast (\mathcal{V},\mathcal{F})$, $\mathcal{V}$ is a countable good covering, That is, $H^\ast (M,\mathbb{R})=\lim\limits_{c.g.c-\mathcal{V} }H^\ast (\mathcal{V},\mathbb{R})$, c.g.c=countable good covers. Then, we know that for countably good covering $\mathcal{V}$, $H^\ast (\mathcal{V},\mathbb{R})\cong H^\ast _{dR}(M)$. Since the restriction mapping is a chain mapping, and $\delta$ are commutative. It can be seen on the double complex network that the restricted mapping between countable good covers will induce isomorphism. Therefore, each term in $H^\ast (M,\mathbb{R})=\lim\limits_{c.g.c-\mathcal{V} }H^\ast (\mathcal{V},\mathbb{R})$ is $H^\ast _{dR}(M)$, Thus $H^\ast (M,\mathbb{R})\cong H^\ast _{dR}(M)$.
