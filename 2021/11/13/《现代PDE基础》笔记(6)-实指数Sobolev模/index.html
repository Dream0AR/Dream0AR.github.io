Real exponential Sobolev space ------------------ Below I hope to give a definition for $H^{m,p}(\mathbb{R}^n)$ when $m$ is a real number. Consider the case of $p=2$, let $H^{m,2}$ be $H^m.$ Since $H^m(\mathbb{R}^n)\subset L^2(\mathbb{R}^n)\subset \mathscr{S}'(\mathbb{R}^n),$ Fourier transformation can be performed on it. From the transformation properties, we have: $$\begin{aligned} \parallel f\parallel_{H^m}&=(2\pi)^{-n}\left(\sum_{|\alpha|\le m}\parallel\xi^\alpha \widehat{f}(\xi)\parallel_{L^2}^2\right)^\frac{1}{2}\\ &\sim \parallel(1+|\xi|^2)^{\frac{m}{2} }\widehat{f}(\xi)\parallel_{L^2}. \end{aligned}$$ So for $s\in \mathbb{R}^n,$ The real exponential Sobolev space can be defined $H^s(\mathbb{R}^n)\subset \mathscr{S}'(\mathbb{R}^n),$ Equipped with model $$\parallel f\parallel_{H^s}=\parallel(1+|\xi|^2)^{\frac{s}{2} }\widehat{f}(\xi)\parallel_{L^2}.$$ When $s$ is a non-negative integer, the above derivation process is consistent with the original definition of $H^{s,2}$. It can be proved that it is also the complete space of $C_c^\infty(\mathbb{R}^n)$, Equipped with an inner product compatible with the norm. Similarly, one can define a homogeneous module $$|f|_{\dot{H}^s}=||\xi|^s\widehat{f}(\xi)|_{L^2}.$$ For real exponential Sobolev spaces, we have the following Sobolev inequality: **Theorem 1.1**. *$\,\forall\,s>\frac{n}{2},$ We have the following inequality:* $$\parallel f\parallel_{L^\infty}\le C\parallel f\parallel_{H^s}, \quad\,\forall\,f\in C_c^\infty(\mathbb{R}^n).$$ **Proof:** By Fourier inverse transformation, $f(x)=(2\pi)^{-n}\int_{\mathbb{R}^n} e^{ix\cdot \xi}\widehat{f}(\xi)d\xi,$ So $$\parallel f\parallel_{L^\infty}\le (2\pi)^{-n}\parallel\widehat{f}\parallel_{L^1}\le \parallel(1+|\xi|^2)^{\frac{s}{2} }\widehat{f}(\xi)\parallel_{L^2}\parallel(1+|\xi|^2)^{-\frac{s}{2} }\parallel_{L^2}=C\parallel f\parallel_{H^s}.$$ It is easy to see that we also have the following facts: **Theorem 1.2**. *$(H^s(\mathbb{R}^n))^\ast =H^{-s}(\mathbb{R}^n).$* **Certificate:** $\,\forall\,f\in H^s(\mathbb{R}^n),$ $g\in H^{-s}(\mathbb{R}^n),$ we have $$\int_{\mathbb{R}^n} f\overline{g}dx=(2\pi)^{-n}\int_{\mathbb{R}^n} (1+|\xi|^2)^s\widehat{f}(\xi)(1+|\xi|^2)^{-s}\overline{\widehat{g} }(\xi)dx\le (2\pi)^{-n}\parallel f\parallel_{H^s}\parallel g\parallel_{H^{-s} }.$$ So $H^{-s}(\mathbb{R}^n)\subset (H^s(\mathbb{R}^n))^\ast .$ On the other hand, if $g\in (H^s)^\ast ,$ $g\in \mathscr{S}'(\mathbb{R}^n).$ by the same formula, $$\left<{}f,g\right>=(2\pi)^{-n}\left<{}(1+|\xi|^2)^s \widehat{f},(1+|\xi|^2)^{-s}\widehat{g}\right>\le C\parallel f\parallel_{H^s}=C\parallel(1+|\xi|^2)^s\widehat{f}(\xi)\parallel_{L^2}.$$ Since $(1+|\xi|^2)^s \widehat{f}(\xi)$ is dense in $L^2$ (including $C_c^\infty$), $(1+|\xi|^2)^{-s}\widehat{g}\in (L^2)^\ast =L^2,$ Thus $\parallel g\parallel_{H^{-s} }=\parallel(1+|\xi|^2)^{-s}\widehat{g}\parallel_{L^2}<\infty,$ $g\in H^{-s}(\mathbb{R}^n).$ Thus $(H^s(\mathbb{R}^n))^\ast =H^{-s}(\mathbb{R}^n).$ Negative Integral Exponential Sobolev Space ------------------- For general $H^{m,p},$ define $H^{-m,p'}:=(H_0^{m,p})^\ast \subset \mathscr{D}',$ $\frac{1}{p}+\frac{1}{p'}=1,$ equipped with operator norm. At this time $C_c^\infty$ is also dense in it. According to the previous theorem, It can be known that the compatibility of $H^s$ and $H^{s,2}$ is also correct when $s$ is a negative integer exponent. trace theorem ------ **Theorem 1.3** (Trace theorem). *$\,\forall\,f\in C_c^\infty(\mathbb{R}^n),$ Let $x'=(x_2,\cdots,x_n),$ $\pi f(x')=f(0,x').$ We have the following inequality:* $$\parallel\pi f\parallel_{H^{s-\frac{1}{2} }(\mathbb{R}^{n-1})}\le C\parallel f\parallel_{H^s(\mathbb{R}^n)},\quad \,\forall\,s>\frac{1}{2}.$$ **Proof:** Let $F_{n-1}f(x_1,\xi')=g(x_1,\xi')$ do $n-1$ Fourier transformations for $f$. Then $$\widehat{f}(\xi)=\int_{\mathbb{R} }e^{-ix_1\xi_1}g(x_1,\xi')dx_1,\quad g(x_1,\xi')=\frac{1}{2\pi}\int_{\mathbb{R} }e^{ix_1\xi_1}\widehat{f}(\xi)d\xi_1.$$ Note that $\widehat{\pi f}(\xi')=g(0,\xi')=\frac{1}{2\pi}\int_{\mathbb{R} }\widehat{f}(\xi)d\xi_1,$ And $$\begin{aligned} \int_{\mathbb{R}^n}|\widehat{f}|d\xi_1&\le \left(\int_{\mathbb{R} }\left|\left(1+|\xi|^2\right)^{\frac{s}{2} }\widehat{f}\right|^2d\xi_1\right)^{\frac{1}{2} }\left(\int_{\mathbb{R} }\left|\left(1+|\xi|^2\right)^{-\frac{s}{2} }\right|^2d\xi_1\right)^\frac{1}{2}\\ &\le C\left(\int_{\mathbb{R} }\left|\left(1+|\xi|^2\right)^{\frac{s}{2} }\widehat{f}\right|^2d\xi_1\right)^{\frac{1}{2} }\left(\int_{\mathbb{R} }\left(1+|\xi_1|+|\xi'|\right)^{-2s}d\xi_1\right)^\frac{1}{2}\\ &\le C\left(1+|\xi'|^2\right)^{\frac{-s+\frac{1}{2} }{2} }\left(\int_{\mathbb{R} }\left|\left(1+|\xi|^2\right)^{\frac{s}{2} }\widehat{f}\right|^2d\xi_1\right)^{\frac{1}{2} } \end{aligned}$$ So, $$\begin{aligned} \parallel\pi f\parallel_{H^{s-\frac{1}{2} }(\mathbb{R}^{n-1})}&\le\frac{1}{2\pi} \parallel(1+|\xi'|^2)^{\frac{s-\frac{1}{2} }{2} }\int_{\mathbb{R} }|\widehat{f}(\xi)|d\xi_1\parallel_{L^2(\mathbb{R}^{n-1})}\\ &\le C\parallel\left(\int_{\mathbb{R} }\left|\left(1+|\xi|^2\right)^{\frac{s}{2} }\widehat{f}\right|^2d\xi_1\right)^{\frac{1}{2} }\parallel_{L^2(\mathbb{R}^{n-1})}=C\parallel f\parallel_{H^s(\mathbb{R}^n)} \end{aligned}$$ The proposition is proved. $\,\forall\,f\in H^s(\mathbb{R}^n),$ It does not make sense to change the value of $f$ on the zero test set, Therefore, just taking $f(0,x')$ has no practical significance and cannot reflect the properties of $f$. However, according to the trace theorem, We know that when $\{f_\nu\}\in C_c^\infty(\mathbb{R}^n),$ When $f_\nu\xrightarrow{H^s}f$, $\{\pi f_{\nu}\}$ constitutes $H^{s-\frac{1}{2} }(\mathbb{R}^{n-1})$Cauchy column. Note that its convergence to $\pi f,$ is called the **trace** of $f$. The trace defines the value of the function at the boundary, Reflect its boundary properties. By flattening technique and unit decomposition, for $f\in H^s(\Omega),$ We can also define its trace on the boundary $\pi f\in H^{s-\frac{1}{2} }(\partial \Omega).$ The commonly used case is $s=1$, In particular, there are $\parallel\pi f\parallel_{L^2(\partial\Omega)}\le C\parallel f\parallel_{H^1(\Omega)}.$ The memory space $H_0^1(\Omega)$ is the complete space of $C_c^\infty(\Omega)$ in module $H^1$. After giving the definition of trace, in fact we can prove $$H_0^1(\Omega)=\{f\in H^1(\Omega),\pi f=0\}.$$ This gives another equivalent characterization of $H_0^1(\Omega)$. Poincaré inequality --------------- **Theorem 1.4** (Poincaré inequality). *For the bounded region $\Omega,$ $f\in H_{0}^{1,p}(\Omega),$ $p\in[1,\infty),$ we have the following inequality:* $$\parallel f\parallel_{L^p}\le C(\Omega)\parallel\nabla f\parallel_{L^p}$$ **Certificate:** Just give the proof for $f\in C_c^\infty(\Omega)$. $\,\exists\,L>0$ makes $\Omega\subset [-L,L]^n.$ Then $f(x)=\int_{-L}^{x_1}\partial_1f(y_1,x')dy_1.$ So $$\begin{aligned} |f(x)|&\le \int_{-L}^L |f_1(y_1,x')|dy_1\\ &\le (\int_{-L}^L|f_1|^pdy_1)^{\frac{1}{p} }(2L)^{\frac{1}{q} }\\ \parallel f\parallel_{L^p}&\le 2L\parallel f_1\parallel_{L^p}\le 2L\parallel\nabla f\parallel_{L^p} \end{aligned}$$ compact embedding theorem ---------- For the bounded region $\Omega,$ by Sobolev's inequality and basic analysis, $$\parallel f\parallel_{L^p(\Omega)}\le C\parallel f\parallel_{H^{m,q}(\Omega)},\quad \,\forall\,\frac{n}{p}\ge \frac{n}{q}-m.$$ Therefore there is embedding $H^{m,q}(\Omega)\hookrightarrow L^p(\Omega).$ When the inequality is strict, That is $\frac{n}{p}>\frac{n}{q}-m,$ We can prove that the embedding is compact, 即将有界集映到列紧集. Obtaining the strict inequality sign can indicate that the embedding is compact, roughly because derivatives can be used at this time, Proved through the Ascoli-Arzela lemma. That is, assuming $\frac{n}{p}=\frac{n}{q}-s,$ then roughly $$H^{m,q}\stackrel{c}\hookrightarrow H^{s,q}\hookrightarrow L^p$$ Since embeddings are continuous, to map convergence columns to convergence columns, it is only necessary to indicate that the first embedding is compact. However, $H^{s,q},$ has not been defined for general $q$, so the above explanation is only formal. The specific proof will be given directly without the help of $H^{s,q},$. We can give a proof for the defined case when $p=2$. We show that for $s>t>0,$ there is a compact embedding $$H^s(\mathbb{R}^n)\stackrel{c}\hookrightarrow H^t_{loc}(\mathbb{R}^n).$$ Here $f\in H^t_{loc}(\mathbb{R}^n)$ satisfies $\,\forall\,\varphi\in C_c^\infty(\mathbb{R}^n),$ The function of $\varphi f\in H^t(\mathbb{R}^n)$. **Lemma 1.5**. *$\,\forall\,f\in C_c^\infty(\mathbb{R}^n),$ $s>t>0,$ We have the following inequality:* $$|f(x+h)-f(x)|_{\dot{H}^t(\mathbb{R}^n)}\le C|h|^{s-t}|f|_{\dot{H}^s(\mathbb{R}^n)}.$$ **Proof:** We might as well set $s-t\in (0,1).$ and just add points between $(s,t)$ for the general case. $F[f(x+h)-f(x)]=(e^{-ih\cdot \xi}-1)\widehat{f}(\xi).$ Note that $|e^{-ih\cdot\xi}-1|\le 2$ or $C|h\cdot\xi|,$ Therefore $|e^{-ih\cdot \xi}-1|\le C|h|^{s-t}|\xi|^{s-t}.$ thus $$|f(x+h)-f(x)|_{\dot{H}^t(\mathbb{R}^n)}\le C|h|^{s-t}\parallel|\xi|^{s}\widehat{f}(\xi)\parallel_{L^2(\mathbb{R}^n)}=C|h|^{s-t}|f|_{\dot{H}^s(\mathbb{R}^n)}$$ **Corollary 1.6**. *$|\alpha_\varepsilon\ast f-f|_{\dot{H}^t(\mathbb{R}^n)}\le C\varepsilon^{s-t}|f|_{\dot{H}^s(\mathbb{R}^n)}$* Therefore, let $\{f_{\nu}\}$ be $\dot{H}^s(\mathbb{R}^n)$ bounded function sequence, Then $\,\forall\,\varepsilon>0,$ $\{\alpha_\varepsilon\ast f_\nu\}$ is $C^m$ bounded function sequence, $\,\forall\,m>t+1.$ Therefore, according to the Arzela-Ascoli lemma, there is a subsequence that converges on any compact set $C^{m-1}$, That is, $C_{loc}^{m-1}$ is compact. Naturally, the convergence sequence also converges in the modular sense of $H^{m-1}$, Therefore, $H^{m-1}_{loc}$ is compact. And $H^{m-1}\hookrightarrow H^t$ is a continuous embedding, Therefore $\{\alpha_\varepsilon\ast f_\nu\}$ is $H^t_{loc}$ compact. By inference, Consistently for $\nu$ we have $\alpha_\varepsilon\ast f_{\nu} \xrightarrow{\dot{H}^t} f_{\nu},$ It can be proved by the diagonal method that $\{f_{\nu}\}$ has a Cauchy subsequence, so $H^t_{loc}$ is compact. Therefore, the embedding of $H^s(\mathbb{R}^n)$ to $H^t_{loc}(\mathbb{R}^n)$ is tight. The article was last updated on 2021-11-13 18:16:30
