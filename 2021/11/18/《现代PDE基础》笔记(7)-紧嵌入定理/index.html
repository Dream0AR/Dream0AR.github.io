compact embedding theorem ---------- The following proves the embedding $$\Vert f\Vert_{L^p(\Omega)}\le C\Vert f\Vert_{H^{m,q}(\Omega)},\quad \,\forall\,\frac{n}{p}\ge \frac{n}{q}-m,$$ When the inequality is strict, i.e. $\frac{n}{p}>\frac{n}{q}-m,$ the embedding is compact, Map bounded sets to compact sets. First, let us simplify the proof. Assume that $m=1$ has been proved, then $\,\forall\,m>1,$ Take $q_1>q,$ such that $\frac{n}{q_1}-1=\frac{n}{q}-m<\frac{n}{p},$ Thus from Sobolev's inequality, we have $$H^{m,q}\hookrightarrow H^{1,q_1}\stackrel{c}\hookrightarrow L^p$$ Therefore, embedding maps bounded sets to bounded sets and then to compact sets. Therefore, we only need to prove the situation when $m=1$. Assume that $p>q$ has been proved, then when $p\le q$, $\,\exists\,p_1>q\ge p,$ $\frac{n}{q}>\frac{n}{p_1}>\frac{n}{q}-1.$ has embedding $$H^{1,q}\stackrel{c}\hookrightarrow L^{p_1}\hookrightarrow L^p.$$ This maps bounded sets to column compact sets and back to column compact sets, so we only need to prove the case $p>q$. At this time $\frac{n}{q}>\frac{n}{p}>\frac{n}{q}-1.$ First we consider the following lemma: **Lemma 1**. *$\,\forall\,f\in C_c^\infty(\mathbb{R}^n),$ $\frac{n}{p}=\theta+\frac{n}{q}-1,$ $\theta\in(0,1), $ We have the following inequality:* $$\Vert f(x+h)-f(x)\Vert_{L^p(\mathbb{R}^n)}\le C|h|^{\theta}\Vert f\Vert_{H^{1,q}(\mathbb{R}^n)}.$$ **Proof:** In fact, the right side can take a homogeneous module. Remember $\frac{n}{p}>\frac{n}{q}-1=\frac{n}{p_1}.$ $q0,$ $\{\alpha_\varepsilon\ast f_\nu\}$ is $H^{m,q}$ bounded function sequence, $\,\forall\,m\ge 1.$ Because the derivation of $\alpha_\varepsilon\ast f_{\nu}$ can be attributed to $\alpha_\varepsilon$. Suppose that $\frac{n}{q}-m<-1,$ has $\frac{n}{q}-m<-1,$ for a sufficiently large $m$. Then according to the Sobolev inequality in the negative exponential case, $\{\alpha_\varepsilon\ast f_\nu\}$ is $C_{loc}^1$ bounded. Therefore, according to the Arzela-Ascoli lemma, there is a subsequence that $C^0$ converges on any compact set, That is, $C_{loc}^{0}$ is compact. Naturally, a convergent sequence on a compact set also converges in the modular sense of $L^{p}$, Therefore it is $L^{p}_{loc}$ compact. By inference, Consistently for $\nu$ we have $\alpha_\varepsilon\ast f_{\nu} \xrightarrow{L^p} f_{\nu}.$ It can be proved by the diagonal method that $\{f_{\nu}\}$ has a subsequence that becomes a Cauchy sequence on any compact set, Thus $L^p_{loc}$ is compact. Therefore, the embedding from $H^{1,q}(\mathbb{R}^n)$ to $L^p_{loc}(\mathbb{R}^n)$ is tight. Introduction to PDE ------- Call $\sum_{|\alpha|\le m}a_\alpha(x)\partial^\alpha u=f(x)$ to be $m$ order linear PDE, $a_\alpha,f\in C^\infty.$ If the solution $u\in C^m,$ is called **classical solution**; If $u\in C^{m-1},$ has the first type discontinuity of order $m$ only along the normal direction on the surface $\{\psi(x)=0\}$, For other $C^m,$, $u$ is called **weak discontinuity solution**. This surface is called **weak discontinuity surface**. If the surface $\psi(x)=x_1=0,$ then the normal derivative is $\frac{\partial {} }{\partial {}x_1}.$ For a weak discontinuous solution $u,$ if $\beta=(m,0,\cdots,0),$ is on the surface $\psi(x)=0$, There is $a_\beta(x)\neq 0,$ then there is a small neighborhood near the point, Make $$\partial_{x_1}^m u(x)=\sum\limits_{\begin{subarray}{c} |\alpha|\le m\\ \alpha\neq \beta \end{subarray} } \frac{a_\alpha(x)}{a_\beta(x)}\partial^\alpha u(x)\in C^0$$ It is inconsistent with $u$ being a weak discontinuity solution. Therefore $a_\beta(x)=0$ occurs along the weak discontinuity surface. For any surface $\psi(x)=0,$, through the flattening technique, let $y_1=\psi,$ $y_i=x_i,$ then $$\left\{\begin{aligned} \frac{\partial {}u}{\partial {}x_1}&=\frac{\partial {}u}{\partial {}y_1}\frac{\partial {}\psi}{\partial {}x_1}\\ \frac{\partial {}u}{\partial {}x_i}&=\frac{\partial {}u}{\partial {}y_1}\frac{\partial {}\psi}{\partial {}x_i}+\frac{\partial {}u}{\partial {}y_i} \end{aligned}\right.$$ At this time, the weak discontinuity surface satisfies $\widetilde{a}_\beta(x)=\sum_{|\alpha|\le m}a_\alpha(x)(\nabla \psi)^\alpha=0.$ Call $\psi(x)=0$ a **characteristic surface**, If it satisfies $\sum_{|\alpha|\le m}a_\alpha(x)(\nabla \psi)^\alpha=0.$ Call its normal direction **characteristic direction**. Therefore, the weakest discontinuity surface must be a characteristic surface*. In PDE theory, a classic existence theorem is the Cauchy-Kovalevskaya theorem. It shows that if the parameter functions are all real analytic, then given any analytic initial value, Analytical solutions are always the only ones that exist. However, the technology used by this theorem is older, We use a modern approach to illustrate. We consider the solution $\frac{\partial {}u}{\partial {}t}=F(t,x,u,\nabla u),$ Transformed into an integral equation $u(t,x)=u_0(x)+\int_0^t F(\tau,x,u,\nabla u)d\tau.$ In ODE theory, since derivatives are no longer involved in $F$, We can use Picard iteration method to get the unique solution. If we can get a suitable module $\Vert\cdot\Vert$ about $x$, So that $\Vert\nabla u\Vert$ can be better controlled, then for $$\Vert u(t,x)\Vert\le \Vert u_0\Vert+\int_0^t \Vert F(\tau,x,u,\nabla u)\Vert d\tau,$$ It can be analyzed and processed from the ODE perspective. In particular, a theoretical estimate of the solution can be given in this way. For general functions, it is obviously impossible to use $\Vert u\Vert$ to control $\Vert\nabla u\Vert.$ But for analytic functions, the derivative and the function value are integrated, so such a module can be obtained. For the analytic function $f(x)=\sum_\alpha \frac{\partial^\alpha f(0)}{\alpha!}x^\alpha,$ Let its convergence radius be $R.$ Then $\,\forall\,r\le R,$ is defined $$\Vert f\Vert_r=\sum_\alpha \frac{|\partial^\alpha f(0)|}{\alpha!}r^{|\alpha|}<\infty.$$ Obviously it is a module, and satisfies $\Vert fg\Vert_r\le \Vert f\Vert_r\Vert g\Vert_r.$ In particular $\Vert f^n\Vert_r\le \Vert f\Vert_r^n.$ A function $f$ is analytic if and only if there exists $r$ such that $\Vert f\Vert_r<\infty.$ Since the derivative term only appears in the integral, we only need to control $\Vert\nabla u\Vert:$ in the integral sense $$\begin{aligned} \left\Vert\int_{0}^t \partial_{x_1} u(\tau,x)d\tau\right\Vert_{R-MT}&\le \int_0^t \sum_\alpha \frac{|\partial^\alpha \partial_{x_1}u(\tau,0)|}{\alpha! (\alpha_1+1)}(\alpha_1+1)(R-MT)^{|\alpha|}d\tau\\ &\le \int_0^t \sum_{\alpha} \frac{|\partial^\alpha u(\tau,0)|}{\alpha!}(R-M\tau)^{|\alpha|} \frac{\alpha_1}{R-MT}\left(\frac{R-MT}{R-M\tau}\right)^{|\alpha|}d\tau\\ &\le \sup_{\tau\in[0,t]}\Vert u(\tau,x)\Vert_{R-M\tau} \int_0^t\sum_k \frac{k}{R-MT}\left(\frac{R-MT}{R-M\tau}\right)^kd\tau\\ &=\sup_{\tau\in[0,t]}\Vert u(\tau,x)\Vert_{R-M\tau} \int_0^t \frac{R-M\tau}{(MT-M\tau)^2} d\tau\\ &=C(M,R,T,t)\sup_{\tau\in[0,t]}\Vert u(\tau,x)\Vert_{R-M\tau} \end{aligned}$$ Note that the analytic radius of the solution is not necessarily fixed, and may decay over time $t$, Therefore, the model taken during analysis cannot be examined on a fixed $r$. However, the C-K theorem only explains the existence and uniqueness of understanding. Hadamard pointed out that the **stability** of the solution also needs to be considered.
