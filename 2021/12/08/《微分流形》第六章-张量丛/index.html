external algebra ------ **Corollary 1**. *If $r>n,$ then $\Lambda^r(V^\ast )=\{0\}.$ If $0\le r\le n,$ then $\dim \Lambda^r(V^\ast )=\binom{n}{r}, $ is based on $\{\omega^{i_1}\wedge\cdots\wedge \omega^{i_r}|1\le i_1<\cdotsn$, the summation set is the empty set, $\Phi\equiv 0.$ $0\le r\le n$, Just prove that $\{\omega^{i_1}\wedge\cdots\wedge \omega^{i_r}|1\le i_1<\cdotsn$, the backside summation set is the empty set; when $r+s\le n$, using the condition, Do the outer product with $\omega^1\wedge\cdots\wedge\omega^r$. Due to linear independence, the following coefficients are all zero. **Proposition 5**. *Suppose $f\in \mathcal{L}(V;W),$ $f^\ast :\Lambda^r(W^\ast )\rightarrow\Lambda^r(V^\ast )$ is the pullback mapping, then $f^\ast (\Phi\wedge\Psi)=f^\ast \Phi\wedge f^\ast \Psi.$* **Proof:** Just use the commutativity of $f^\ast $ and $A,\otimes$: $$\begin{aligned} f^*(\Phi\wedge\Psi)(x_1,\cdots,x_{r+s})&=(\Phi\wedge\Psi)(f(x_1),\cdots,f(x_{r+s}))\\ &=\frac{(r+s)!}{r!s!}A(\Phi\otimes \Psi) (f(x_1),\cdots,f(x_{r+s}))\\ &=\frac{(r+s)!}{r!s!}A(f^*(\Phi\otimes \Psi))(x_1,\cdots,x_{r+s})\\ &=f^*\Phi \wedge f^*\Psi (x_1,\cdots,x_{r+s}). \end{aligned}$$ Do the direct sum of the form $\Lambda(V^\ast )=\bigoplus_{r=0}^n \Lambda^r(V^\ast )=\{\omega_0+\cdots+\omega_n|\omega_r\in \Lambda^r(V^\ast )\}.$ Then it becomes a $2^n$-dimensional vector space, and with $\wedge$ as the multiplication that satisfies the distributive law, it becomes algebra. Call it the **external algebra** on $V^\ast $. Similarly, You can define $\Lambda(V)=\bigoplus_{r=0}^n \Lambda^r(V),$ It is called **external algebra** on $V$. tensor bundle ------ Let $M^m$ be an $m$-dimensional $C^\infty$ manifold, $\,\forall\,p\in M,$ has a tangent space $T_pM.$ We define $(r,s)$-type tensor space $T_s^r(p)=T_pM\otimes\cdots\otimes T_pM\otimes T_p^\ast M\otimes\cdots\otimes T_p^\ast M.$ $\dim T_s^r(p)=m^{r+s}.$ Define the bundle space $T_s^r(M)=\bigcup_{p\in M}T_s^r(p),$ Natural topology and differential structure can be given to make it a $m+m^{r+s}$-dimensional $C^\infty$ manifold. $T_s^r(q)$ has natural basis $\{\frac{\partial {} }{\partial {}x^{i_1} }\otimes\cdots\otimes\frac{\partial {} }{\partial {}x^{i_r} }\otimes dx^{j_1}\otimes \cdots\otimes dx^{j_s}|1\le i_1,\cdots,i_r,j_1,\cdots,j_s\le n\}.$ $\Phi\in T_s^r$ has coordinates $(\Phi^{i_1\cdots i_r}_{j_1\cdots j_s}).$ Take $\pi:T_s^r(M)\rightarrow M$ as the natural projection, $\Psi:\pi^{-1}(U)\rightarrow U\times \mathbb{R}^N$ maps $\Phi$ to $(q,(\Phi^{i_1\cdots i_r}_{j_1\cdots j_s})).$ Then define $$\widetilde{\Psi}=(\varphi\times \mathrm{id}_{\mathbb{R}^N})\circ \Psi:\pi^{-1}(U)\rightarrow U\times \mathbb{R}^N\rightarrow \varphi(U)\times \mathbb{R}^N\subset \mathbb{R}^{m+N}.$$ The topology assigned to $T_s^r(M)$ is such that $\pi^{-1}(U)$ is an open subset of $T_s^r(M)$ and $\widetilde{\Psi}$ is homeomorphic. If $\{(U_\alpha,\varphi_\alpha)\}$ is the smooth coordinate atlas of $M$, Then $\{(\pi^{-1}(U_\alpha),\widetilde{\Psi}_\alpha)\}$ is the smooth coordinate atlas of $T_s^r(M)$. It satisfies the following properties, $\pi:T_s^r(M)\rightarrow M$ is surjective to $C^\infty$, $\pi^{-1}(q)=T_s^r(q)$ is $m^{r+s}$ dimensional vector space, $\Psi:\pi^{-1}(U)\rightarrow U\times \mathbb{R}^N$ is reflected by $C^\infty$, $\pi_1\circ \Psi=\pi,$ and $\Psi|_q$ are linear isomorphisms. These elements make it a **vector bundle**, which is called a **tensor bundle**. tensor field ------ If $\Phi:M\rightarrow T_s^r(M),$ satisfies $\pi\circ\Phi=\mathrm{id}_M,$ Then $\Phi$ is said to be a $(r,s)$-type **tensor field** on $M$. When $\Phi$ is a smooth mapping, It is called a smooth $(r,s)$-type **tensor field**. This is if and only if each component of $\Phi$ is a smooth function. $\Phi\in T_s^r(p)=\mathcal{L}(T_p^\ast M,\cdots,T_p^\ast M,T_pM,\cdots,T_pM;\mathbb{R})$ can be regarded as $(r+s)$-heavy linear function. Consider $(0,s)$-type tensor field $\Phi.$ and take any $X_1,\cdots,X_s\in \mathfrak{X}(M),$ Define the role of the tensor field on the vector field: $$[\Phi(X_1,\cdots,X_s)] (p):=\Phi(p)(X_1(p),\cdots,X_s(p)),$$ Then $\Phi(X_1,\cdots,X_s)\in C^\infty(M).$ because each component is a smooth function, After linear combination or multiplication, it is still a smooth function. Since the tensor is a multilinear function, any $f_1,\cdots,f_s\in C^\infty(M),$ Considered point by point $$\Phi(f_1X_1,\cdots,f_sX_s)=f_1\cdots f_s\Phi(X_1,\cdots,X_s)\in C^\infty(M).$$ conversely, If there is a mapping $\Phi:\mathfrak{X}(M)\times \cdots\times \mathfrak{X}(M)\rightarrow C^\infty(M)$ is $C^\infty(M)$ linear, Then $\Phi$ must be a $(0,s)$-type $C^\infty$-tensor field. Generally, let $\Gamma(T_s^r(M))$ represent the entire $(r,s)$-type tensor field of $C^\infty$, Then it is an infinite-dimensional vector space, $f\Phi+g\Psi(p):=f(p)\Phi(p)+g(p)\Psi(p).$ Similar to the previous one, it acts on the combination of cotangent vector field and vector field, And it is also $C^\infty(M)$ linear. The reverse is also true. external differential form ---------- $M^m$ is a $C^\infty$-manifold. Let $\Lambda^r(T^\ast M)=\bigcup_{p\in M}\Lambda^r(T_p^\ast M),$ Similarly, Give it natural topological structure and differential structure to make it a $m+\binom{m}{r}$-dimensional $C^\infty$ manifold, It is called the $r$-sub **external form bundle** on $M$. If $\Phi:M\rightarrow \Lambda^rT^\ast M$ is a smooth mapping, $\pi\circ\Phi=\mathrm{id}_M,$ then $\Phi$ is said to be $r$-time **external differential form**. This is if and only if its components are smooth functions. Let $\mathcal{A}^r(M)=\Gamma(\Lambda^rT^\ast M)$ be the totality of $r$-sub-external differential forms, is an infinite-dimensional vector space. Similarly, You can also define $f\omega_1+g\omega_2\in \mathcal{A}^r(M).$ Since we have multiplication $\wedge,$ on $\Lambda^r T^\ast M$ We can define $\wedge point by point:\mathcal{A}^r(M)\times \mathcal{A}^s(M)\rightarrow \mathcal{A}^{r+s}(M).$ That is $$(\omega\wedge\sigma)(p)=\omega(p)\wedge \sigma(p)\in \Lambda^{r+s}(T_p^\ast M).$$ Of course it also satisfies the distributive law, the anti-commutative law and the associative law.
