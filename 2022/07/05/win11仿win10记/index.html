Win11仿Win10记 Win11 imitates Win10
DreamAR
 2022-07-05 14:57:12  
  • 技术笔记 
 

新到手的Surface开始默认装Win11了，倒腾了半天恢复了Win10的手感。有的地方感觉还是传统设计舒服，很多改动感觉中看不中用…记录一下可以调整哪些东西恢复Win10的感觉。

任务栏设置

把很多不必要的隐藏了，然后最重要的任务栏居左对齐，让别人看不出这是Win11。

右键菜单设置

是不是找不到你的Git Bash here或者其它右键菜单里的东西了？别慌，不是你安装错误或者Win11不兼容了，而是它隐藏在了右键菜单里最下栏的“显示更多选项”里。Win11的新右键菜单虽然好看但是却很不实用，如果经常要用软件设置的额外菜单选项的话，每次都得点一下。有没有办法可以默认开启更多选项呢？有的！我们只需要修改注册表即可。方法详见这篇文章，原理及其他方式可以看这里。

本地安全策略

在修改cmd权限时（默认以管理员模式打开cmd），发现适用于Win10的方法不行了，在控制面板中没有“本地安全策略”这一选项。似乎Win11家庭/教育版中没有安装这个东西。可以按照该教程把它安装回来。好像必须编写成脚本启动，不能在cmd里手动输入。

The newly acquired Surface started to have Win11 installed by default, and it took me a long time to restore the feel of Win10. In some places, the traditional design still feels comfortable, and many changes feel unsatisfactory... Record what can be adjusted to restore the feeling of Win10.

Taskbar settings

I hide a lot of unnecessary stuff, and then align the most important taskbar to the left so that others can’t tell it’s Win11.

Right-click menu settings

Can't find your Git Bash here or other things in the right-click menu? Don’t panic, it’s not that you installed it incorrectly or that Win11 is incompatible, but that it is hidden in the “Show more options” in the bottom column of the right-click menu. Although Win11's new right-click menu looks good, it is very impractical. If you often use the additional menu options set by the software, you have to click it every time. Is there a way to enable more options by default? some! We just need to modify the registry. For details on the method, see this article, the principles and other methods can be found here.

Local security policy

When modifying the cmd permissions (open cmd in administrator mode by default), I found that the method applicable to Win10 did not work. There is no "Local Security Policy" option in the control panel. It seems that this thing is not installed in Win11 Home/Education Edition. You can install it back according to this tutorial. It seems that it must be written as a script to start, and cannot be entered manually in cmd.
