Win11仿Win10记 Win11 imitates Win10
DreamAR
 2022-07-05 11:57:12  
  • 技术笔记 
 
The new Surface began to install Win11 by default, and it took half a day to restore the feel of Win10.Some places still feel comfortable with traditional design, and many changes don't look good... Record what can be adjusted to restore the feeling of Win10. # # Taskbar Settings Hide a lot of unnecessary, and then align the most important taskbar to the left, so that others can't see that this is Win11. # # Right click menu settings Can't find your Git Bash here or something else in the context menu?Don't panic, it's not that you have an installation error or that Win11 is incompatible, but that it's hidden in the "Show more options" bar at the bottom of the right-click menu.The new right-click menu in Win11 is nice, but not very practical. If you often want to use the extra menu options set by the software, you have to click it every time.Is there a way to turn on more options by default?Yes! We just need to modify the registry. For detailed instructions, please refer to this article: (https://www.xitongzhijia.net/xtjc/20220629/246207.html#:~:text=Win11%E5%8F%B3%E9%94%AE%E8%8F%9C%E5%8D%95%E5%A6%82%E4%BD%95%E7%9B%B4%E6%8E%A5%E9%BB%98%E8%AE%A4%E6%98%BE%E7%A4%BA%E6%9B%B4%E5%A4%9A%E9%80%89%E9%A1%B9%201%E3%80%81%E9) %A6%96%E5%85%88%E7%94%A8%E9%BC%A0%E6%A0%87%E5%8F%B3%E9%94%AE%E7%82%B9%E5%87%BB%E2%80%9C%E5%BC%80%E5%A7%8B%E2%80%9D%E6%8 C%89%E9%92%AE%EF%BC%88%E6%88%96%E8%80%85%E6%8C%89Win%2BX%E9%94%AE%EF%BC%89%EF%BC%8C%E9%80%89%E6%8B%A9%E7%82%B9%E5%87%BB, %E 2% 80% 9CWindows % 20% E7% BB % 88% E7% AB % AF % EF % BC % 88% E7% AE %A 1% E7% 90% 86% E5% 91% 98% EF % BC % 89% E2% 80% 9D %E 3% 80% 82), the principle and other methods can be found [here] (https://www.zhihu.com/question/480356710). # # Local Security Policy When modifying the cmd permission ([Open cmd in admin mode by default] (https://blog.csdn.net/weixin_46157208/article/details/120250560)), it was found that the method for Win10 is no longer working, and there is no "Local Security Policy" option in the control panel.It seems that this item is not installed in Win11 Home/Education Edition.You can install it back by following [this tutorial] (https://blog.csdn.net/m0_63920681/article/details/122413895).It seems that it must be scripted to start and cannot be entered manually in the cmd.
